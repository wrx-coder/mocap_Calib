## 数据处理约定

- 本目录 CSV 记录的是静止位置，不作为运动轨迹处理。
- 每个文件代表一次独立采集，不合并三次采集的坐标。
- 一个 Marker 在一次采集中的静态坐标：仅使用 XYZ 同时有效的帧，对 XYZ 分别取算术均值。
- 不需要时间范围内的抖动分析；后续使用静态结果，不使用逐帧时间序列、位置标准差或速度/加速度。
- 空值不视为零，不插值；保留有效帧数和总帧数仅用于记录数据覆盖情况。
- 坐标单位为 mm，坐标系为 World。原始 CSV 保持不变，角色标记写入配置和派生结果。

## 标定注意事项

- 所有文件的 Rigid0 位姿为空；三个 board 文件中的 torso 位姿也为空。参考刚体应使用已识别的四个 Marker 静态坐标，不使用这些空字段。
- sphere 文件中的 torso 位姿有效，但其 Marker 对应关系尚未确定。
- 参考刚体的点间距离跨采集发生变化，不能直接共用固定几何模板。例如 101563–101597 的三次均值分别为 96.778、118.943、119.517 mm；101563–101573 分别为 213.942、214.331、219.750 mm。
- 上述是不同采集之间的几何变化，不是单次采集时间范围内的抖动。原因尚未确定，可能涉及 Marker 移动、结构变化或 ID 对应变化，标定前需要核查。

## 文件与复现

- `marker_roles.json`：Marker 角色、板角环绕顺序及识别状态配置。
- `parse_mocap_csv.py`：原始多层表头 CSV 解析器。
- `identify_marker_groups.py`：板子/参考刚体分组的复现脚本（依赖 numpy）。
- `parsed/marker_groups.json`：此前几何识别的详细记录，仅供追溯。
- `export_static_positions.py`：按本记录导出带角色标记的静态坐标（仅依赖 Python 标准库）。
- `parsed/static/*_static.csv`：每次采集每个 Marker 一行，无逐帧时间和抖动指标。
- `parsed/static/all_static_positions.csv`：所有静态坐标合并表，仍保留采集文件名，未对不同采集求平均。
- `parsed/static/README.md`：静态导出字段和使用说明。
- 之前的 `parsed/*_flat.csv` 和 `*_summary.json` 保留作为历史解析结果，后续以 `parsed/static/` 为准。

重新导出静态结果：`python3 export_static_positions.py`。
