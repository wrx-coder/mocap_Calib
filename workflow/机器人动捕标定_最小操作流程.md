# 机器人动捕标定：最小操作流程与 marker 布置

> 用途：把《核心流程》和《首次试采操作指南》整理成可直接用于第一次进场的操作清单。
> 状态：这是操作建议，不表示已实机实施、靶球已选定或标定已通过。
> 本文中的 marker 直径、布置间距和支架错层尺寸是**试采起步建议，不是厂家保证参数**；最终按现场可见性、跟踪质量和深度有效性确定。

## 1. 两个文件分别讲什么

- [机器人动捕标定_核心流程.md](机器人动捕标定_核心流程.md)：最终求什么外参、如何使用数据、如何验收与重标。
- [首次试采操作指南.md](首次试采操作指南.md)：第一次进场如何确认设备、真实 CSV、共同靶球和相机录制链路可靠。

最小主线：

```text
固定相机与胸部刚体
→ 检查动捕数据的字段、单位与缺测
→ 筛选相机和动捕能测同一球心的靶球
→ 录齐 RGB-D、mask 和动捕数据
→ 采 15 个编号静态位置
→ 试算与诊断
→ 通过后补 torso 对齐、正式采集及独立验证
```

第一次的目标是跑通数据链路，不是立即采 200–400 点或宣称正式外参合格。

## 2. 三种 marker 的用途不能混淆

| 用途 | 放在哪里 | 用来干什么 | 首次链路试采是否必需 |
|---|---|---|---|
| 胸部刚体 marker | 与 torso 固定连接的胸部刚性结构或支架 | 给出胸部动捕刚体系的位置、朝向 | 必需；已有可靠正式刚体则沿用 |
| 共同靶球 | 相机前方工作空间内，逐点移动并停稳 | 相机与动捕同时测同一球心，求相机外参 | 必需 |
| torso 特征 marker | CAD 上可精确定位的固定特征处 | 把胸部动捕刚体系对齐到机器人 `torso_link` | 首次可暂缓；最终 torso 外参必需 |

胸部刚体 marker 的安装位置可以按刚性和可见性选择；torso 特征 marker 必须有可靠的 CAD/测量坐标，不能随意贴。

## 3. 用多大的 marker，贴在哪里

### 3.1 胸部刚体：优先 5 颗约 14–16 mm 的标准小 marker

优先使用现场已验证可跟踪的标准规格，例如直径 14 mm 或 16 mm。不必为首次试采先采购特殊尺寸。

这些小 marker **只需要被动捕识别，不需要被 D435i 的 RGB 模型识别**。RGB 看不清胸部小球不影响它们作为动捕刚体 marker 使用。

#### 安装位置

优先选择：

- 与 `torso_link` 固定连接、不活动、不晃动的胸部结构；
- 或牢固固定到胸部的轻型刚性支架/板。

不要安装在：

- 手臂、肩关节等活动部分；
- 腰部以下的 pelvis；
- 线缆、软垫、松动外壳；
- 会相对胸部晃动的支架部件上。

相机与这组 marker 必须相对固定。胸部外壳若存在装配松动，不能仅凭“贴在胸前”就认为满足条件。

#### 布置方式

采用**分散、不对称、有一定前后错层**的布局。不要共线，也不要做成规整正方形。

以下只是布局示意，不是机器人精确安装图：

```text
          胸部正面

      ● A                 ● B

                ● E
              （略向前）

         ● C          ● D

    各点间距不要完全相同
    E 可用牢固小支座形成前后错层
```

起步建议：

- 整组覆盖胸部允许的约 15–25 cm 范围，在安全、刚性和可见性允许时尽量拉开；
- 相邻点间距可从约 5–10 cm 起步，不要求每对相邻点都相同；
- 一个点相对其他点可有约 2–4 cm 的前后错层，前提是不妨碍机器人、不容易被碰掉。

以上不是硬性尺寸。现场需确认多个动捕相机能同时看到足够的点，亮斑不合并，刚体跟踪稳定。

Motar 手册的布置原则是“三点不共线、四点不共面”。数学上三个不共线的对应点可以确定刚体姿态，但实际有遮挡，因此实操推荐 4–5 颗，优先 5 颗。

**已有可靠正式胸部刚体时，先请管理员确认并沿用，不擅自重贴、删除重建或改变原点/朝向。**

### 3.2 共同靶球：先筛 2–3 个接近实际目标尺寸的整球

目标类似苹果大小，首次可优先筛选直径约 **60–80 mm** 的整球候选。例如现场有 60、70、80 mm 时，从中选 2–3 个测试。

注意：

- 60–80 mm 只是筛选起点，不是已经确认的合格尺寸；
- 实际部署球若尺寸不同，优先接近实际部署尺寸；
- 用卡尺至少测三个方向，记录真实直径；
- 必须同时满足 RGB 识别、有效深度、动捕稳定跟踪，以及可核查的同球心依据。

靶球不贴在胸部，而是在相机前方的工作空间内移动。用细的哑光支撑杆或稳定支撑座，避免大面积遮球，也不要挡住相机和动捕视线。

#### 禁止把表面小 marker 当作大球球心

不能在普通大球表面贴一颗 14 mm 小 marker，然后直接把动捕测到的小 marker 球心作为大球球心。

两者不是同一个点，而且大球转动时偏移方向会变化。不能通过随意减去半径或让外参吸收误差来解决。

整球反光靶也不是自动合格：反光表面可能改变 RGB 外观、导致深度空洞，或让动捕大亮斑定位出现偏差。必须实测筛选。

**没有双方都能可靠观测、且同球心依据明确的球，就停在靶球筛选阶段，不正式采几百点。**

### 3.3 torso 特征 marker：5–8 个已知特征，球心坐标必须可靠

可使用同类标准小 marker。选择 CAD 与实机一致、能精确定位的孔位、螺钉位置或外壳特征，分散布置并尽量具有三维展布。

记录的是 marker 球心，而不是外壳表面贴点：

```text
marker 球心
≈ 表面定位点 + 安装方向上的（底座高度 + marker 半径）
```

该表达式只适用于已核实的安装几何。实际底座、方向、偏心，以及 CAD 网格单位、缩放与固定变换均需核实。

这些特征 marker **不要并入胸部刚体资产**。采集时使用实测散点，避免把软件推算的资产点当独立测量。

目前没有具体实机 CAD/URDF 和外壳定位信息，不能直接指定“必须贴哪个孔”或给出精确球心坐标。

## 4. 最终求解分成两段

### 第一段：相机 → 胸部动捕刚体系

同一个静态球的位置：

- 相机得到 color optical 系下的球心 `p_C`；
- 动捕得到世界系下的球心 `p_W`；
- 动捕同时给出胸部刚体位姿 `T_W_R`。

逐帧转换后再对有效静态窗口平均：

```text
p_R(t) = inverse(T_W_R(t)) · p_W(t)
p_R ≈ T_R_C · p_C
```

求得 `T_R_C`，即相机坐标系到胸部动捕刚体系的变换。

### 第二段：胸部动捕刚体系 → 机器人 torso_link

胸部 marker 创建出来的坐标系 `R` 不自动等于 URDF 的 `torso_link`。用已知特征点求 `T_torso_R` 后，才能得到：

```text
T_torso_C = T_torso_R · T_R_C
```

本文使用 `T_A_B` 表示 B → A。

首次试采可以只跑通并试算 `T_R_C`；没有完成 CAD/可靠测量对齐，就不能宣称已得到最终 `T_torso_C`。

## 5. 第一次最小操作流程

### 步骤 0：固定安装与安全状态

- 请管理员确认动捕系统已标定、允许录制。
- 不移动动捕相机，不重设世界系，不擅自修改正式机器人刚体。
- D435i 使用最终支架，锁紧并拍照记录。
- 机器人安全支撑，躯干静止。
- 仅运行感知和录制，不启动机器人控制、抛球或接球。
- 已有可靠胸部刚体则沿用；没有则在基础测试后按第 3.1 节安装并创建。
- 胸部刚体创建后，marker、原点和朝向保持不变。

### 步骤 1：动捕最少做 S1、S2、S3

| 项目 | 最小操作 | 确认内容 |
|---|---|---|
| S1 静态 | 录一个测试刚体和一颗独立小 marker，约 30 s | CSV 包含刚体位置、四元数与实测散点 |
| S2 已知位移 | 独立 marker 沿三个已知方向各移动约 200 mm，端点停稳 | 单位、轴方向、导出缩放正确 |
| S3 遮挡恢复 | 分别遮挡独立 marker 和测试刚体，再恢复 | 缺测表示、旧值保持/预测情况、散点 ID 是否改变 |

遮挡等测试使用测试夹具，不折腾正式机器人刚体。测试夹具的 marker 可以在完成基础测试后用于胸部安装；正式胸部刚体创建后不再移动它们。

CSV 导出要求：

- 勾选实测散点与刚体；
- 打开表头；
- 缩放 1；
- 建议选择 mm，并记录实际单位与坐标转换选项；解析不能硬编码 mm；
- 保留原始录制帧率；
- 不填补、不平滑、不抽帧、不用 Excel 改写；
- 保存原软件录制、直接导出的 CSV 和导出设置截图。

### 步骤 2：筛选共同靶球

每个候选球在实际工作区的近、中、远位置分别停约 10 s，两套设备同时录制。

检查：

1. RGB 能识别该球，mask 覆盖真实球，未碰图像边界。
2. 球区域有足够有效数值深度，不主要来自背景或空洞。
3. 动捕能稳定得到对应散点，没有明显假点或频繁缺测。
4. 球心尽量不动时，改变表面/接缝朝向，输出没有明显异常跳变；若球心随支撑移动，需如实记录。
5. 有合理可核查依据说明两边输出对应同一几何球心；稳定输出单个散点本身不能证明绝对球心正确。

近、中、远按实际部署范围选择，不强制使用 1、2、3 m，也不强制达到 4 m。

若球与当前 RGB-D 路径不兼容，先解决靶球/观测问题，不立即扩展到 IR、双目或复合靶路线。

### 步骤 3：核查实际配置并录齐相机数据

当前主线：

```text
RGB 彩色图 → 分割 mask → 对齐深度
→ 相机系表面观测或已补偿球心
```

内参已完成，保存真实 CameraInfo/标定文件即可，不另做内参标定。

至少保存：

- RGB；
- 对齐到 RGB 的深度；
- CameraInfo；
- 检测 mask 及对应图像/时间信息；
- 实际加载的启动配置与算法配置；
- frame、时间戳、深度单位、分辨率和检测设置；
- 实测球直径、半径补偿设置，以及输出是否已经补过半径。

尽量同时保存原生深度与相机内部外参，便于核查 depth-to-color 几何及对齐深度的 z 定义。

禁止只拿现有程序的 world/pelvis 点作为标定输入：这些点已经使用过待标定外参。必须保留外参变换前的相机观测，或完整原始输入以便离线重建。

核验实际消息数量和内容，不能仅凭话题名称存在就认为录制成功。现有 mask 节点若依赖 TF 且不能正常输出，先记录阻塞项，不用伪造 TF 宣称链路已通过。

### 步骤 4：采 15 个编号静态位置

建议安排 **3 个距离层 × 每层 5 个位置**：

```text
每个距离层：

             上
             ●

     左 ●    ● 中    ● 右

             ●
             下
```

所有位置均在两套设备共同可见区，尽量覆盖实际工作空间，避免图像边界和遮挡。

操作：

1. 编号 `sample_01` 至 `sample_15`。
2. 每个位置停 3–5 s。
3. 记录相机和动捕各自对应的片段/时间段。
4. 分析时取中间稳定且双方有效的静态窗口，至少保留约 0.3 s 有效数据。
5. 录制前后可各增加一个较长静止段，便于核验顺序。
6. 漏段就标注、删除或重采，不将后续段顺延强行配对。

这是静态点对采集，首次无需先完成逐帧精确时间同步，但必须确认两侧窗口对应同一停稳位置。

配对日志建议：

| sample_id | 距离层/位置 | 动捕片段及时间段 | 相机片段及时间段 | 异常/是否有效 |
|---|---|---|---|---|
| sample_01 | 近/中 | 待填写 | 待填写 | 待填写 |
| sample_02 | 近/左 | 待填写 | 待填写 | 待填写 |

### 步骤 5：试算与诊断，通过后再扩大采集

优先检查：

- 单位与坐标系是否正确；相机使用实际 color optical 系。
- 动捕球心与相机球心是否是同一物理点。
- 相机观测是前表面还是已补偿球心，禁止重复加半径。
- mask 内深度统计是否适合现有球心补偿模型。
- 深度是否可靠，散点 ID 变化是否正确关联。
- 15 个位置是否一一对应。
- 残差是否随距离、视场区域或球朝向明显变化。

默认球半径固定为实测值、深度尺度固定为 1。不要为了降低残差随意增加偏置参数。

这 15 点用于数据链路预演和问题诊断，不用于宣称正式精度达标。

通过后：

1. 完成或核验 `T_torso_R` 的 CAD/可靠测量对齐。
2. 正式采 200–400 个独立位置，覆盖至少 4 个深度层与工作视场。
3. 提前留出约 20% 独立位置作验证，不用训练点充当验证点。
4. 报告留出位置 3D RMSE、P95 和按距离/区域误差；初始目标为 RMSE < 2 cm。
5. 检查训练分半重复结果；初始目标为旋转差 < 0.5°、平移差 < 1 cm。
6. 单独检查 torso 对齐质量；其重复测量初始目标为旋转差 < 0.5°、平移差 < 3 mm。

这些数值是工程目标，不是设备保证。正式流程还必须通过软件合成闭环自测。

## 6. 最小流程可暂缓哪些项目

| 项目 | 何时追加 |
|---|---|
| S0 空场 | 出现明显背景假点或环境异常 |
| S4 刚体旋转与资产点语义 | 四元数解释不清、局部坐标检查异常，或需要调查资产点 |
| C2 双向 IR 互扰 | 两套设备同时运行时出现深度异常、假点或缺测 |
| torso CAD 对齐 | 首次链路试采可暂缓；最终 torso 外参不可省 |
| 正式 200–400 点 | 共同靶球与录制链路通过后再做 |

《首次试采操作指南》开头明确优先 S1/S2/S3、共同靶球筛选、C0/C1/C3；末尾部分交付检查项覆盖了更完整的 S0–S5。执行最小流程时，按开头优先级安排，条件追加项未做则注明“未做/原因”，不能勾选为已完成。

## 7. 物品与离场检查清单

### 物品

- [ ] 场地管理员协助与录制许可。
- [ ] 5 颗约 14–16 mm 或现场已验证规格的刚体 marker；已有正式胸部刚体则无需新增。
- [ ] 1 颗独立测试小 marker。
- [ ] 可固定 4–5 颗 marker 的哑光刚性测试夹具；可与最终安装 marker 分阶段复用。
- [ ] 2–3 颗接近实际目标尺寸的整球候选；60–80 mm 可作为苹果大小目标的筛选起点。
- [ ] 稳定哑光球支撑、卡尺/尺子、遮挡物。
- [ ] 相机和数据存储的可靠供电、足够存储空间。

### 离场前

- [ ] 原软件录制与 CSV 均可打开，未改写原始 CSV。
- [ ] 保存版本、场地状态、导出单位/缩放/坐标/帧率设置。
- [ ] S1 有真实刚体位姿与独立实测散点。
- [ ] S2 有已知方向及实测长度记录。
- [ ] S3 有真实缺测区间记录。
- [ ] 候选球的直径、材质、支撑方式与共心依据已记录；未知项明确写未知。
- [ ] RGB、深度、CameraInfo、mask 真正录到有效消息。
- [ ] 15 个 sample_id 的双侧静态窗口可一一对应。
- [ ] 未使用表面小 marker 冒充大球球心，未重复补半径。
- [ ] 未把依赖未标定 TF 的世界点当相机独立输入。
- [ ] 修改过的测试设置已恢复，数据已有备份。

数据统一保存到：

```text
data/raw/<session_id>/
├── mocap/   # 原工程、CSV、资产等
├── camera/  # 原始图像/深度、CameraInfo、mask、配置等
└── notes/   # 照片、设置截图、球尺寸、配对表与异常日志
```

原始数据默认不入 Git，不上传公开仓库的完整现场画面或个人信息。具体采集命令需在确认真实硬件、驱动与话题后制定，本文不假定已有可直接运行的采集脚本。

## 8. 一句话执行方案

**胸部固定 5 颗约 14–16 mm 的标准小 marker，采用非对称分散布局；用 2–3 颗接近部署尺寸的整球筛选共同靶球；先检查 CSV、单位与缺测，再录齐 RGB-D/mask 并采 15 个编号静态位置。没有同球心依据不扩大采集，没有 torso 对齐就只称 `T_R_C`，不称最终 torso 外参。**
