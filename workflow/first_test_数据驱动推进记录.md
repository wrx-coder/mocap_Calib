# first_test：根据已有数据推进工作流

本记录对应真实 `data/raw/first_test/` 与 `data/processed/first_test/`，替代早期“尚未收到真实数据”的状态描述。**已推进到离线候选求解与交叉诊断，未完成独立验收或机器人部署。**

## 本轮执行

1. 阅读核心标定流程、精准抓球路线、数据契约和 first_test 静态处理约定。
2. 保留原始 bag/CSV、已归档数据和已有配置；后续每次采集独立静态平均，不做时间抖动、速度或加速度分析。
3. 在原始 RGB 上用明确 ROI/阈值提取真实 marker 轮廓；生成单球二值 mask，拒绝缺测和多候选歧义，不生成占位 mask。
4. 用动捕实测板角几何和 RGB 板角做 PnP，枚举录制配对与角顺序，不依赖缺失深度单位、码族、码边长和胸部位姿。
5. 枚举单球三次录制的六种配对，通过相似变换求深度尺度候选；以轮廓面积估球半径，并检查固定单位/半径敏感性。
6. 对单球同帧胸部位姿做 W→R 后静态平均，求条件性 `T_R_C`；不把动捕刚体 `torso` 当作机器人 `torso_link`。
7. 对板与单球结果交叉检查，保存不一致和不可辨识证据，不放宽正式验收门槛。

## 缺项如何处理

| 原缺项 | 使用已有数据的处理 | 结果与限制 |
|---|---|---|
| 目标 mask | 原始同帧 RGB 轮廓提取 | 已生成真实单球 mask；模型/轮廓几何仍待独立核验 |
| 两侧录制对应 | 枚举几何配对，而非按编号直接强配 | 板、单球均得到明显最优对应；仅 `geometry_inferred`，非人工确认 |
| 板尺寸/码族 | 直接用四角动捕实测坐标 | 得到 marker 中心间距，不冒充板外形或码边长 |
| 板录制刚体位姿缺失 | 在导出 World 系求 `T_W_C` | 不填补原空位姿，不伪造参考刚体模板 |
| 深度单位 | 单球相似变换反求尺度 | 约 `0.001007078 m/raw`；依赖轮廓/表面模型，不等于驱动参数已证明 |
| 球半径 | 轮廓等效面积结合尺度估计 | 约 `6.87 mm`；阈值相关，不等于尺测实值 |
| 世界轴与四元数约定 | 保持 World 原导出基；R 系显式条件假设 | 世界 PnP 不猜轴；R 系采用 xyzw R→W 假设，待现场/资产核验 |
| `T_torso_R` | 不存在 torso_link 特征对应 | 不能从无 CAD/可靠测量的数据唯一恢复；不生成最终机器人外参 |
| 独立留出/分半检查 | 现有三点全部用于诊断 | 不把帧拆分冒充位置留出，不发布 hardware_accepted |
| 抓取工具中心/控制状态 | 无手部夹具、关节状态与时钟映射 | 不能恢复；本轮不控制机器人 |

## 数值结果

以下为全帧静态聚合结果，**拟合误差不等于独立验证精度**：

- 板 RGB-PnP：重投影 RMSE **0.353 px**；次优配对 **8.554 px**。
- 板第二次录制只有下方两角可见；交叉诊断 **1.699 px**，不补造图外角。
- 单球：最优训练拟合 RMSE **2.83 mm**；次优配对 **63.51 mm**。
- 条件性胸部 R 系单球刚性拟合误差约 **1.3–1.9 mm**，仅三个拟合位置，无独立验证。
- 板与单球外参差 **4.206° / 24.25 mm**；板外参预测单球像素偏差约 **16.58、33.68、24.36 px**。不能将两组混成已验证外参。
- 自由联合估计尺度/半径得到非物理负半径 **−85.19 mm**，未采用；现有点不支持可靠自由补偿。
- 参考四点跨次距离变化最大约 **27.95 mm**，不能据此补原空刚体位姿。
