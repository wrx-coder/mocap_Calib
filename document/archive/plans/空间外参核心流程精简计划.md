## Approach
- 暂按“部署同一颗反光球 + 静态采样”作为唯一主线。
- 精简为：固定安装与坐标约定 → 躯干刚体系对齐 → 静态球采样 → 外参与偏置求解 → 独立验证 → 保存部署。
- 仅保留影响结果正确性的前置条件、公式、采样要求和验收项；调研、备选靶、论文讨论不展开。
- 用户已确认：**只保留空间外参标定，页数不限**；排除 `δt`、动态抛球验证、在线接口建设与排期。
- 核查发现并据此优化：
  - `T_torso_R` 可直接由 torso 系已知特征球心与同帧转换后的 R 系实测点配准，避免全程平均世界位姿。
  - 动捕侧采用“逐帧转到 R 系，再段内平均”，与数据层规格一致。
  - 原方案把相机静止段也限定为 2 mm 不适合远距深度噪声；改为动捕 2 mm 起始门限、相机按实测噪声与无趋势判定，并记录样本序号防止错配。
  - 单球留出点只能直接验证位置误差，不能给出外参旋转真值 RMS；旋转用重复/分半解的一致性衡量。
  - 外参仍为 SE(3) 六自由度；径向偏置与深度尺度仅在实际检测管线需要时作为干扰参数，避免把尺度写进外参矩阵。
  - 输出光学系外参，写入相机 link 前显式转换；不直接用 optical 外参覆盖 `d435_joint`。

- [x] 新建核心流程文档，按以下顺序组织，每步明确输入、操作、产出：
  1. **定义与准备**：统一 `T_A_B`、m、xyzw；固定最终支架，胸部建刚体并冻结资产；实测所用 optical frame、内参和检测管线；完成单球可见性与双向 IR 互扰检查。
  2. **对齐 `T_torso_R`**：选 5–8 个分散特征点，校核网格单位和 link 变换，补偿 marker 球心高度；实测点逐帧转 R 系，Kabsch 从 R 配准到 torso；留一与 2–3 次静态重复检查。
  3. **采球点对**：同一部署球、同一检测代码；200–400 个位置、至少 4 深度层、覆盖实际工作视场；停稳 0.5–2 s，取内部至少 0.3–0.5 s 的有效静态窗口。
  4. **清洗与配对**：CSV 取 Marker 而非 RigidBodyMarker，空间关联而非仅按 ID；先转 R 后平均；样本序号/静态窗核对，两路缺段不强行按顺序配；留出独立验证位置，展布协方差最小/最大奇异值比至少 1/20。
  5. **求解 `T_R_C`**：无尺度 Kabsch 初值；用 SciPy 加权 Huber 精化，按实际测量采用像素/视差或各向异性 xyz 残差；仅需要时估计径向偏置/深度尺度，不引入自由形常数偏置；明确补偿作用方向。
  6. **静态验收**：留出点 3D RMSE、分深度/区域误差和异常段回查；对齐重复差 < 0.5°/3 mm、外参分半差 < 0.5°/1 cm、位置 RMSE < 2 cm、像素 RMSE < 2 px（有对应观测时）均标为原方案的初始工程目标，而非设备保证。
  7. **组合与保存**：`T_torso_C = T_torso_R · T_R_C`；需要 link 外参时 `T_torso_link = T_torso_C · T_C_link`，核对 optical/link 固定变换来源；保存矩阵、相机配置、补偿参数、资产、原始数据和验收报告。
- [x] 文末仅留简短失败排查与重标规则，不展开替代标定路线；单球/物理模型无法通过验收时停止发布结果，回查原 v4。
