# 工作区约定与接口（骨架）

> **当前状态更新**：离线核心模块已实现，包含 CSV/静态处理、RGB-D几何、torso配准、外参求解、验收与CLI。本文表格保留最初模块分工；现行可执行字段与命令见 [数据契约 v1](标定数据契约_v1.md) 和根 README。算法合成闭环已验，不等于实机通过。

## 1. 模块分工

| 路径 | 后续职责 |
|---|---|
| `src/dc_mocap/io/` | 表头驱动的 FZMotion CSV 解析，保留原始约定；在线接口不在本次范围 |
| `src/dc_mocap/model/` | 会话、刚体轨迹、散点、有效掩码与静态段模型；统一单位、轴及四元数 |
| `src/dc_mocap/geom/` | 项目唯一的 SE(3)/SO(3) 工具来源；相机标定模块复用，不再写另一套 |
| `src/dc_mocap/process/` | 质量检查、散点关联、静止段切分、逐帧转 R 系、聚合和展布 |
| `src/dc_mocap/products/` | P1/P2 写出与元数据契约 |
| `src/dc_mocap/sim/` | 合成 CSV 和已知真值场景 |
| `src/dc_calib/camera/` | 相机记录读取、静态观测与检测管线适配 |
| `src/dc_calib/alignment/` | torso 特征对应、无尺度配准、留一与重复验证 |
| `src/dc_calib/solver/` | `T_R_C` 初值及加权精化；按实际管线选择 `r/s` |
| `src/dc_calib/validation/` | 留出集、分半一致性、分区域误差和工程验收 |
| `src/dc_calib/export/` | 组合、optical/link 转换、标定包输出；不自动改机器人 URDF |

离线 CLI 为 `dc_calib.cli`；核心包不依赖 ROS。ROS bag 解包、模型推理与传感器采集由既有程序/外层适配器提供，不以伪结果替代。

## 2. 最小数据契约

每个处理会话位于 `data/processed/<session_id>/`，可包含：

| 产品 | 每行/内容 | 必须保留 |
|---|---|---|
| P1 `torso_features.csv` | 一个特征球心簇 | 标签、R 系均值、协方差、帧数、质量标记 |
| `torso_correspondences.csv` | 一个确认的特征对应 | `feature_id`、R 系球心、torso 系已知球心；对应依据另存 |
| P2 `ball_static_samples.csv` | 一个动捕静止段 | `sample_id`、段编号、起止时间及所属时钟、R 系均值、协方差、帧数、质量标记 |
| `camera_static_samples.csv` | 一个相机静止段 | 同类标识与统计、实际 frame、观测类型；原生像素/视差或 xyz 与补偿状态 |
| `sample_pairs.csv` | 一个双侧确认的对应位置 | `sample_id`、两侧段 ID、train/validation 划分与有效状态 |
| `meta.yaml` | 会话溯源 | 原始文件路径/哈希、配置与资产版本、单位、坐标定义、相机配置、代码版本 |

动捕散点与胸部刚体任一无效则丢弃该帧；先逐帧转 R 后平均。缺测用有效掩码/NaN，不以零填补；相机侧阈值按实测噪声确定，不强套动捕 2 mm 门限。

`sample_id` 是采集位置身份，段 ID 是各侧记录身份，不能混为同一个概念。散点 ID 仅为辅助，不保证遮挡后不变。训练/验证按位置分组，不按同一位置的帧随机拆分。

骨架提供的 CSV 仅有表头，**不是实际 FZMotion 原始格式，也不是完整产品 schema**。完整 P1/P2 字段沿用 [数据层规格](动捕数据层_设计规格.md)；拿到真实样例后再确定相机原生观测字段与 schema 版本。

## 3. 配置路径与未确认值

- 全部模板使用 YAML，`null` 明确表示未确认，不允许静默猜测源单位、坐标或 frame。
- 后续配置加载器统一把相对文件路径解释为**工作区根目录相对路径**，不能依赖运行时碰巧所在的目录。库 `dc_calib.config.preflight` 使用显式工作区根路径。
- `configs/session.example.yaml` 关联相机/求解模板；真实配置建议复制到 `configs/local/<session_id>/` 并将引用改为对应文件。
- 变换统一存储为带 source/target frame 的 4×4 SE(3)，四元数若使用则 xyzw。未知变换用 `null`，不放占位单位矩阵。
- 所有像素观测必须带真实通道及分辨率。已有球心补偿要显式声明；raw 与 corrected 数据不得混用。

## 4. 结果契约

`outputs/calibration/<session_id>/<version>/` 保存：

- `T_torso_R`、`T_R_C`、`T_torso_C` 及 frame/单位/来源。
- 若需要 link 外参，另存 `T_C_L`、`T_torso_L`；不默认只有光学旋转。
- `r/s` 如使用则单独保存，并注明补偿对象与公式；不把尺度写进旋转块。
- 配置、资产、原始数据和特征/样本对应的溯源引用，以及验收报告。
- `validation_status` 明确区分未验证、通过与失败；只有通过的结果可供正式部署。

工具结果使用真实/合成来源与验收状态区分；没有真实录制时仅可得到合成结果，不当实机外参。
