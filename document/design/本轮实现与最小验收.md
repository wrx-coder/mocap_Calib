# 本轮实现与最小验收

根据DDL反馈，取消逐阶段开发审批，完成一次离线模块集成。保留原计划步骤顺序：文档/模板→数据约定→共享几何→preflight→闭环/验收。

## 已实现

- D435i/color optical/RGB-D 核心流程，详细试采操作，记录表。
- SE(3)/四元数及显式基变换；配置检查、点产品与元数据。
- 多层表头 FZ CSV 与明确单位的long CSV；逐帧转R、手工静态窗、空间门限跟踪ID恢复、质量统计。
- 已校准 CameraInfo 导入、已有 mask + color-z depth 的离线球心几何，支持Brown去畸变。
- torso球心对应Kabsch、相机点对Kabsch/Huber精化、可选surface深度尺度。
- 独立留出 RMSE/P95/分深度与区域、分半一致性；版本化JSON导出。
- CLI demo 与实录处理接口。未复制私有源码、没有启动设备/机器人控制、没有推送。

## 验证

已执行 `python3 -m pytest -q`：**15 passed**。CLI help、Python语法、文档链接及 `git diff --check` 均通过。端到端demo生成80个位置、保留16个验证位置，经过读取/聚合/关联/求解/组合/导出。结果只标 synthetic_pass，不是实机精度承诺。本轮固定seed=7演示留出RMSE约0.178 mm；这是合成噪声场景，不代表D435i实测精度。

现场只需小批试采确认数据/共心，再用正式数据独立留出（初始RMSE<2cm）与一次分半一致性检查，不要求每个小配置一份人工报告。
