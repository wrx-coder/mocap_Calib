# 机器人动捕标定：空间外参核心流程

> **目标**：利用 FZMotion 与机器人头部相机对同一颗球的静态观测，求出相机相对 `torso_link` 的六自由度外参 `T_torso_C`。
> **主线**：固定安装 → 躯干动捕刚体系对齐 → 静态单球采样 → 配对与求解 → 独立静态验收 → 保存部署。
> **范围**：仅空间外参。不包含时间偏移标定、动态接球验证、在线接口建设、备选靶与调研论证。深度尺度、球面到球心的补偿仅在检测管线需要时处理，不属于外参矩阵。

## 1. 定义与采集准备

### 1.1 统一坐标与单位

| 符号 | 定义 |
|---|---|
| `W` | 动捕世界系 |
| `R` | 胸部动捕刚体系，**不是** `torso_link` |
| `torso` | URDF 的 `torso_link` 系 |
| `C` | 实际球检测输出使用的相机 optical frame；默认采用 left-IR optical，必须现场核对 |
| `L` | URDF 中需要写入外参的相机 link，例如 `d435_link` |

统一规定：`T_A_B` 把 B 系的点变到 A 系，`p_A = R_A_B p_B + t_A_B`。内部长度用 **m**，角度计算用 rad，四元数按 **xyzw** 存储并单位化；坐标系为右手系。动捕世界系建议统一为 Z-up，相机 optical 系仍采用 **x 右、y 下、z 前**。

最终变换链：

```text
p_R       = inverse(T_W_R) · p_W
T_torso_C = T_torso_R · T_R_C
p_torso   = T_torso_C · p_C_center
```

`p_C_center` 必须是球心，不能直接把深度测得的球前表面当作球心。公式中 `T · p` 是三维点的刚体变换简写，即 `R p + t`；误差向量仍是三维。

### 1.2 开始前检查

**输入**：最终安装的相机、胸部 marker 刚体、部署用球、相机配置和机器人模型。

1. **安装定型**：相机与胸部刚性连接，支架和工作视场已确定；后续不再调整角度或位置。只检查实际工作区覆盖，不在本文展开安装角设计。
2. **冻结刚体**：在胸部建立 `R`，导出 FZMotion 资产。之后不移动 marker、不删除重建资产、不做“质心调整 / 刚体旋转”。
3. **固定感知配置**：记录相机序列号、分辨率、帧率、内参及来源、曝光、发射器、滤波和对齐设置，核对检测代码版本与输出 frame。
   - IR 像素与深度必须有正确的对应关系，不能混用 IR 像素和 depth-to-color 对齐后的深度。
   - 若观测实际在另一 optical frame，先使用已核对的相机内部外参转换到 `C`。
4. **确认检测管线**：明确是“IR 定位 + 深度取值”还是“双目 IR 三角化”，以及代码是否已补偿球半径或深度尺度。后续不能重复补偿。
5. **确认共同观测有效**：使用部署时同一颗球、同一套检测代码。在工作区近处、远处和边缘试采，确认 FZMotion 能稳定输出单个散点且球尺寸适合相机检测；验证两侧观测对应同一物理球心。大尺寸反光球的动捕系统偏差不能默认等于标准小 marker 的精度。
6. **检查双向 IR 互扰**：分别检查 D435 发射器对动捕掉点/假点的影响，以及动捕频闪对 IR 检测的影响。按部署状态测试，不以临时关闭必要发射器的方式通过检查。
7. **静态固定机器人**：在符合设备安全要求的保护架/固定支撑下保持躯干静止、相机正常供电；不要依靠站立平衡控制维持静止。
8. **动捕导出**：保留原始数据，使用四元数，不做填充或平滑；采集期间关闭自校准，不重设世界系。CSV 的 mm 在接入时转为 m，轴方向、手性与四元数方向先做实测检查。

**产出**：固定的资产与相机配置、明确的 `C` 定义、确认可用的单球观测管线。任何一项未通过，不进入正式采样。

## 2. 对齐躯干动捕刚体系：求 `T_torso_R`

**输入**：胸部刚体 `R`；机器人 CAD/网格；5–8 个可精确对应的躯干特征。

1. 选择分散、尽量非共面的螺钉、孔位或棱角，优先扩大几何基线。若使用头壳点，须确认其固定连接和装配可靠性。
2. 核对网格长度单位、缩放、visual origin 及固定关节变换，把每个特征转换到 `torso` 系。
3. 在已知特征处放置 marker；根据实际安装几何补偿底座厚度和 marker 半径，得到**球心**坐标 `q_torso,k`。特征 marker 不并入胸部刚体资产。
4. 静态录制并导出同一份 CSV，使用实测 **Marker 散点列**与同帧的 `T_W_R(t)`，逐帧计算后再平均：

   ```text
   p_R,k(t) = inverse(T_W_R(t)) · p_W,k(t)
   p̄_R,k    = mean_valid(p_R,k(t))
   ```

5. 用**无尺度 Kabsch** 将 R 系特征点配准到 torso 系：

   ```text
   q_torso,k ≈ R_torso_R · p̄_R,k + t_torso_R
   ```

   得到 `T_torso_R`；不要反向保存成 `T_R_torso`。
6. 留一法检查：每次少用一个特征求解，再预测该特征位置，记录误差与异常特征。调整机器人整体位置/姿态后停稳，重复静态采集 2–3 次，比较所得 `T_torso_R`。

**产出**：`T_torso_R`、特征对应表、留一误差及重复一致性报告。初始工程目标为重复旋转差 **< 0.5°**、平移差 **< 3 mm**；留一误差应与特征定位和 marker 安装精度相符。模型/装配误差明显时，不把低拟合残差当作对齐准确的证据。

## 3. 采集静态球点对

**输入**：已经定型的安装与感知管线、`T_torso_R`、同一颗部署球。

| 项目 | 操作要求 |
|---|---|
| 位置数量 | 目标 **200–400 个有效静止位置**，不是 200–400 帧 |
| 深度分布 | 至少 **4 个深度层**，覆盖实际工作距离，不只在一个平面采样 |
| 视场分布 | 各深度层覆盖中心、边缘及上下左右；相机与动捕均能有效观测 |
| 每点停留 | 移动后停稳 **0.5–2 s**，取内部至少 **0.3–0.5 s** 的有效静态窗口；噪声大时延长 |
| 球的支撑 | 哑光持球杆或稳定支撑；手和手臂不遮挡动捕，避免其他反光物干扰 |
| 采集记录 | 为每次停留记录唯一 `sample_id`、顺序、粗略时间和位置备注；相机与动捕录制覆盖同一次停留 |
| 原始数据 | FZMotion 工程与 CSV（散点 + 胸部刚体）；相机 bag/原始 IR、深度或双目检测观测 |

**静态判定**：动捕位置标准差 **< 2 mm** 可作为起始门限，并检查胸部姿态稳定。相机远距深度噪声可能超过 2 mm，不能套用同一门限；应依据该距离的实测噪声，确认像素/深度无持续移动趋势。两侧用于平均的窗口必须处在**同一次停稳区间内**。

**产出**：带样本序号的双侧原始观测与停留记录。静态采集不要求逐帧精确同步，但不能把移动段混入平均或把相邻停留误配。

## 4. 清洗、配对与展布检查

**输入**：CSV、相机观测和停留记录。

1. **选对数据**：球和特征点使用 `Marker` 实测散点，默认不使用可能来自模板推算的 `RigidBodyMarker` 资产点。VRPN 只提供刚体，不能替代单球 CSV 散点。
2. **关联物理球**：散点 ID 遮挡后可能改变，依据空间连续性、速度门限及人工记录关联；排除胸部 marker 与其他反光物。出现多个候选时人工核对，不能盲选。
3. **剔除无效观测**：缺测、跳变、误检、深度空洞、明显饱和失真及起停过渡帧不参与平均；球散点或同帧胸部刚体位姿任一无效，该帧均丢弃。不用零值或插值填补。
4. **先变换、后平均**：动捕每帧执行 `p_R(t) = inverse(T_W_R(t)) · p_W(t)`，再对有效静态窗口平均；不要“先平均世界点，再乘平均刚体位姿”。相机保留原生观测和样本统计，至少记录均值、协方差、有效帧数、起止时间与质量标记。
5. **核对配对**：按 `sample_id`、顺序与静态窗人工/程序交叉检查。两侧数量不同、漏段或窗口明显不对应时，修复记录或删除该位置的双侧数据，**不把后续段整体错位配对**。
6. **预留验证集**：求解前固定独立位置作为留出集，例如有效位置的 20%；各深度层和视场区域均有覆盖。同一位置的帧不能分散到训练与验证两侧。
7. **检查展布**：训练点集去质心后求 3×3 协方差，计算其奇异值：

   ```text
   λ_min / λ_max ≥ 1/20
   ```

   不足时沿最弱展布方向补采。该比值是**协方差**的比值，不是主方向标准差的比值；它只是展布筛查门槛，不保证附加偏置参数也可辨识。动捕 R 系点云可先做预检，再检查相机深度层覆盖。

**产出**：可靠的训练/验证点对、原生相机观测及质量统计。每个样本代表一个独立静止位置。

## 5. 求解相机外参：`T_R_C`

### 5.1 先确定球心观测模型

**输入**：实际检测管线与相机配置。先明确代码输出的是表面点还是球心，再选参数。

| 实际输出 | 处理 |
|---|---|
| 已有可靠球心 xyz | 直接使用，不再加球半径；尺度补偿是否需要由实测决定 |
| IR 定位后读取球前表面深度 | 在模型成立时采用径向球心补偿 `r`；优先固定为实测半径，有足够展布且结果稳定时才联合估计有效 `r` |
| 双目 IR 质心三角化 | 不直接加球半径；确认质心对应球心投影，使用已核对的双目内外参与几何 |

对于**沿视线观测到球前表面**的模型，本文固定补偿方向为：

```text
p_C_raw    = 去畸变后由原始深度反投影的表面点
n          = p_C_raw / ||p_C_raw||
p_C_center = s · p_C_raw + r · n
```

`s > 0` 是对原始 xyz 的乘法尺度，默认 1；`r` 单位为 m，默认使用实测半径。此公式要求 `C` 是该观测射线所属的 optical frame；若原始深度在另一光心下，应先在原生光学系完成补偿，再把球心转换到 `C`。若深度取自不规则斑点/邻域、观测并非视线上的前表面，应先验证模型，不强行用 `r` 吸收误差。对已经补偿过的输出，不重复应用此公式。

**外参始终是 SE(3)**：`T_R_C` 的旋转必须正交且 `det(R)=+1`。`s` 单独保存，不能乘进外参旋转块；不联合拟合自由形常数/线性偏置来掩盖外参误差。

### 5.2 无尺度 Kabsch 初值

以已作初始补偿的球心 `a_i = p_C_center,i` 和动捕真值 `b_i = p_R,i` 建立点对，求：

```text
b_i ≈ R_R_C · a_i + t_R_C
H = Σ (a_i − ā) (b_i − b̄)ᵀ
H = U Σ Vᵀ
R_R_C = V · diag(1, 1, det(V Uᵀ)) · Uᵀ
t_R_C = b̄ − R_R_C · ā
```

使用 numpy/SciPy 的刚体配准即可，**不估尺度**；不要用一般仿射拟合替代六自由度外参。

### 5.3 加权鲁棒精化

- 参数默认 `θ = [rotvec(3), t(3)]`；只在管线需要时增加 `r`、`s`，并设符合物理的边界/先验。旋转不用欧拉角优化。
- 使用 `scipy.optimize.least_squares(loss='huber', x_scale='jac')`。残差先除以噪声标准差/白化，再设置 Huber 阈值，初始可取归一化残差约 **2–3**，随后依据实测噪声核对。
- 由动捕球心预测相机球心：`p̂_C_center = inverse(T_R_C) · p_R`，再按选定观测模型预测相机的原始测量，不能将表面观测与球心预测直接比较。

| 可用观测 | 推荐残差 |
|---|---|
| IR 像素 + 原始视差 | 像素/视差预测误差，分别按 `σ_uv`、`σ_d` 归一化 |
| 左右 IR 像素 | 在左右相机中预测投影，使用 `(u_L, v_L, u_R)` 等经核对的双目观测与噪声模型 |
| 只有 xyz | 使用各向异性协方差白化的 xyz 误差；沿深度方向的噪声随距离增长，不能全部等权 |

对于上述前表面模型，正向预测应先计算：

```text
p̂_C_raw = (p̂_C_center − r · p̂_C_center / ||p̂_C_center||) / s
```

上式要求 `||p̂_C_center|| > r`，且预测原始点位于相机前方；否则判为模型/数据无效。再投影到实际观测通道；视差预测使用**原始表面深度**，而不是球心深度。xyz 退路可对 `p_C_center` 使用补偿后传播得到的协方差，白化 `p̂_C_center − p_C_center`。权重应考虑动捕和相机误差，不能只凭帧数假定系统误差会消失。

若 `r/s` 对初值、子集或采样范围高度敏感，先固定可靠的物理量、补足展布或检查观测模型，不发布不稳定的联合解。正式处理真机数据前，求解实现须用已知变换的合成点对检查方向、旋转约束及补偿模型；本文不假定已有可运行脚本。

**产出**：`T_R_C`、必要的 `r/s` 及明确的作用对象、求解配置与残差报告。

## 6. 独立静态验收

**输入**：冻结后的参数、未参与求解的静态位置与对齐报告。验证期间不再调参；若根据验证集改模型，须重新采集/划定独立验证集。

对每个验证位置计算：

```text
e_R,i     = T_R_C · p_C_center,i − p_R,i
e_torso,i = T_torso_C · p_C_center,i − T_torso_R · p_R,i
3D RMSE   = sqrt(mean(||e_R,i||²))
```

这两种位置残差的范数相同；相机与动捕共享的 `T_torso_R` 误差会在比较中抵消，因此**球点留出验证不能替代第 2 节的独立躯干对齐检查**。

| 检查 | 初始工程目标/判定 |
|---|---|
| 留出位置误差 | **3D RMSE < 2 cm**；同时记录中位数、P95、最大误差及三个方向误差 |
| 像素预测误差 | 有对应原始像素时，**像素 RMSE < 2 px**；三维与像素指标分别报告 |
| 外参分半一致性 | 对训练位置作分层分半，保持各自深度/视场覆盖，分别求解；旋转夹角 **< 0.5°**、平移差 **< 1 cm** |
| 躯干对齐一致性 | 第 2 节重复旋转差 **< 0.5°**、平移差 **< 3 mm**，并报告留一误差 |
| 分区域检查 | 分深度层与视场区域报告，不得用总体均值掩盖边缘/远距系统偏差 |
| 物理合理性 | 在相同坐标系下与最终支架/CAD 比较位置、朝向；明显不符先查坐标与安装，而非直接接受拟合结果 |

以上数值沿用原方案，属于**待实测校准的初始工程目标，不是厂家精度保证或完整误差预算**。单球留出位置不能直接测得外参旋转真值，旋转夹角仅衡量重复解/分半解的一致性。验收同时检查 `r/s` 稳定性与残差是否随深度、视场角呈系统变化；只看训练拟合误差不能通过验收。

**产出**：通过/不通过结论及静态验收报告。未通过不得写入正式部署配置。

## 7. 组合外参并保存部署

**输入**：验收通过的 `T_torso_R`、`T_R_C` 与相机 frame 定义。

1. 组合并保存光学系外参：

   ```text
   T_torso_C = T_torso_R · T_R_C
   ```

2. 使用相机球心定位时：先按第 5 节补偿到 `C` 系球心，再应用 `T_torso_C`。保留原始观测，避免在线管线和标定管线重复补偿。
3. 若要写入 URDF 的相机 link `L`，必须先取得经过核对的 `T_C_L`：

   ```text
   T_torso_L = T_torso_C · T_C_L
   ```

   若驱动给的是 `T_L_C`，先取逆。变换须来自正确的驱动/URDF 固定链与光心定义，不默认只有旋转或平移为零。仅当该关节父节点为 `torso_link` 时，其 origin 才能直接使用 `T_torso_L`；否则换算到实际父节点。**不要直接把 optical 外参填入 `d435_joint`**，也不要同时发布冲突的 URDF 与 tf 变换。
4. 确认最终矩阵末行为 `[0,0,0,1]`，旋转正交、行列式为 +1，位置单位为 m；用一个已知静态点检查整条部署变换链。

**保存清单**：

- `T_torso_R`、`T_R_C`、`T_torso_C`；需要时保存 `T_C_L`、`T_torso_L` 及各自来源。
- 明确的源/目标 frame、xyzw 约定、单位、标定日期与版本。
- `r/s`（如使用）、球尺寸、补偿公式及代码作用位置；相机配置、内参、相机内部外参与检测代码版本。
- FZMotion 工程与资产、原始 CSV/相机录制、特征对应表、样本配对表及训练/留出划分。
- 求解配置、质量统计与验收报告。

**产出**：可追溯的外参标定包与部署配置；保留旧版本，不覆盖唯一原始记录。

## 8. 失败排查与重标规则

**验收失败**：先停止发布，按以下顺序检查，不靠更自由的偏置模型压低残差。

```text
样本错配/混入移动段 → 缺测、误检与互扰 → 单位、轴向、frame 和内参
→ 球心/表面模型及重复补偿 → 点集展布 → 支架/marker 松动 → torso 特征与模型对齐
```

单球或物理补偿模型仍无法通过验收时，保留失败报告，回查 [原 v4 方案](../references/机器人动捕标定方案_v4.md)，不在本流程展开替代路线。

| 变化 | 必须处理 |
|---|---|
| 相机/支架相对胸部移动、拆装或松动 | 重做 `T_R_C`，重新组合 `T_torso_C` 并验收 |
| 胸部 marker 移动；刚体资产重建或原点/朝向改变 | 原 `T_torso_R` 与 `T_R_C` 均失效，重做两段标定 |
| 特征点、外壳装配或 torso 模型定义变化 | 重查/重做 `T_torso_R`；若影响相机或胸部刚体的实际连接，同时重做 `T_R_C` |
| 球、检测代码、内参、分辨率、曝光、深度处理或 frame 设置变化 | 重新核查观测/补偿模型并做独立静态验收；模型或光心变化时重做相应标定，不能默认沿用旧标定包 |
