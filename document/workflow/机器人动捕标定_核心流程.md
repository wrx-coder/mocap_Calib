# D435i + 动捕：空间外参核心流程

> 唯一主线：**RGB 分割 + 深度 → 相机系球心；FZMotion → 胸部刚体系球心；点对配准 → torso 相机外参**。
> 内参已完成，不重新标内参。使用该次标定/实机 CameraInfo 的数值，不抄示例 JSON。这里不做时间标定、在线接球或机器人控制。

## 1. 固定安装与共同靶球

- 相机型号 D435i，目标为苹果大小球体。固定最终支架，胸部 marker 建立刚体 `R` 后不移动、不重建、不改原点/朝向。
- 内部用 m、右手系、四元数 xyzw；`T_A_B` 表示 B → A。相机 `C` 使用 **color optical**（x右/y下/z前）；不是 pelvis，也不是 left-IR。
- 选能同时被 RGB 程序识别、深度有效、动捕稳定跟踪的整球靶标。先试 2–3 个尺寸，量真实直径。**表面小 marker 球心不等于大球球心**；没有共同球心依据就先解决靶标，不采几百点。
- 机器人安全支撑、躯干静止。只录感知，不启动控制/抛球。

## 2. 对齐胸部刚体系与机器人：`T_torso_R`

选 5–8 个分散的已知 torso 特征；通过机器人 CAD/URDF 的固定变换把特征坐标换到 `torso_link`。网格缩放、visual origin、marker 底座厚度与球半径要计入，记录的是球心。

动捕读同帧散点与刚体，先变换后平均：

```text
p_R(t) = inverse(T_W_R(t)) · p_W(t)
q_torso,k ≈ T_torso_R · mean(p_R,k)
```

用无尺度 Kabsch 配准 R → torso。用一次留一/重复测量检查：重复差初始目标 <0.5°、<3 mm。没有 CAD 对应或可靠测量时可先交付 `T_R_C`，**不能冒充已经得到 `T_torso_C`**。

## 3. 同步录制静态位置

先试 12–20 个位置跑通，正式建议 200–400 个独立位置、≥4 深度层、覆盖工作视场。每位置停 0.5–2 s，取内部≥0.3 s 有效窗口；首次试采停 3–5 s 更容易操作。

- 动捕：原始工程与 CSV，勾选实测 Marker 散点和刚体；打开表头，缩放1，记录 m/cm/mm、坐标转换及帧率。不要填补/平滑/抽帧。默认建议导出 mm，但解析不能硬编码 mm。
- 相机：RGB、对齐深度、CameraInfo、mask、实际检测设置、时间/frame/depth units。尽量保留原生深度及内部外参；只有 RGB 图片和最终世界点不够。
- 每个停留用 `sample_id` 编号，记录两侧静态段 ID。缺段就核对/删除，不顺延强配。
- 已有程序的世界点依赖未标定 TF，**不作点对输入**。从外参转换前的相机观测或原始数据重建 `p_C`。

## 4. 相机球心与求解

相机观测必须声明为前表面或已补偿球心：

```text
前表面模型：p_C_center = s * p_C_surface + r * normalize(p_C_surface)
点对约束：p_R ≈ T_R_C · p_C_center
最终外参：T_torso_C = T_torso_R · T_R_C
```

默认半径 `r` 固定为实测值，尺度 `s=1`；**已有球心不再加半径**。实际 mask 内深度统计未必等于沿质心射线的前表面，先看试采残差；不靠任意偏置吸收错误。

RGB 像素去畸变使用已标定内参。aligned depth 必须说明存的是 color z 还是原 depth z；只把深度图搬到 RGB 像素不能证明 z 定义正确。记录原生深度时可先在 depth 系反投影，再用相机内部外参转换。

求解：无尺度 Kabsch 初值 → SciPy 加权 Huber 精化。每位置权重按 xyz 协方差/实测深度噪声；数据不够时固定物理参数，不增加自由度。剔除无效帧后先转 R 再平均；散点ID变化用空间/人工关联，歧义不盲选。

## 5. 只保留三项核心验收

1. **软件自测**：固定合成数据端到端恢复已知外参，并确认单位/frame/重复补偿/退化输入不能静默通过。
2. **真实试采**：12–20 点确认同球心、记录完整、深度与配对正确。正式训练点云协方差最小/最大特征值比建议≥1/20，至少不能共线。
3. **独立静态留出**：提前保留约20%独立位置，报告3D RMSE、P95与按距离/区域误差；初始目标 RMSE<2 cm。训练分半重复初始目标<0.5°/<1 cm。这些是工程目标，不是设备保证；球点互比不能证明共同的 torso 对齐误差，须看第2节。

失败保留报告，不发布正式结果。无需每个小参数单独一轮审批；软件一次性实现、现场数据补齐后再实机验收。

## 6. 输出与重标

保存 `T_torso_R`、`T_R_C`、`T_torso_C`、frame/单位、球尺寸与补偿、配置和输入哈希、样本划分、报告。合成运行仅输出 **synthetic** 包，不能标为实机通过。

写入 link `L` 前：`T_torso_L = T_torso_C · T_C_L`。内部 optical/link 变换使用核对的驱动/URDF 链，不默认只有旋转；本工具不自动修改 URDF。

相机/支架移动重做 `T_R_C`；胸部 marker/资产原点变化重做两段。球/检测/分辨率/补偿改变重新检查观测并验收。
