# 机器人头部相机外参标定 —— 调研与实施方案（v4）

> **目标**：用动捕（MoCap）+ 机器人上的**单个头部相机**，标定**相机相对机器人的外参** `T_torso_C`。
> **硬件**：Unitree G1（详见 §1.4）
> **动捕系统**：元客视界 FZMotion 3.0（Motar）。本文中的 Motive / NatNet / eSync 均已替换为 FZMotion 的对应项；接口、坐标约定、架构约束与待确认项见 `FZMotion动捕系统要点_v4对接.md`。
> **依据**：官方 URDF 复核、FK 可见性计算、偏置参数可辨识性仿真（Fisher 信息）、OpenCV 4.13 API 实测与合成数据验证。全部数字可由随附的 `calib_v3_checks.py` 复现。

**要点**

1. **库**：优化器不手写。闭式初值用 Kabsch（numpy 十行）；复合靶用 OpenCV 4.x 的 `calibrateRobotWorldHandEye`。精化用 `scipy.optimize.least_squares(loss='huber')`，残差函数自己写。
2. **标识物**：优先用部署时那颗反光球。动捕和相机测的是同一个球心，没有"板↔marker"这个额外未知量，还能顺带标出 IR 检测偏置。复合靶 / AprilCube 留作交叉验证。
3. **损失**：球用相机原生噪声空间的加权残差，参数为外参 + 球心径向偏置 + 深度尺度；板用角点重投影误差。两者都加 Huber 核。
4. **数据量**：球取 200–400 个静止位置，每个停 0.3–0.5 s 取平均，≥4 个深度层并铺满视场；板取 30–60 个位姿，绕两个以上的轴转。关键是空间展布而非帧数，采完先算点云协方差的条件比自检。

## 0. 结论速查（TL;DR）

```
前置 1    : 相机安装角（§0.5）。官方 URDF + FK 复核：光轴下倾 47.6°，相机离地
            ≈1.26 m，深度/IR 视场上沿在水平线下 18.6°。任何高度的水平来球，首次可见
            都晚于接触前 ≈210 ms；高于 1.26 m 的球永不可见。阻断成立
            FoV 扫描只回答"改成多少度"。支架未定 → 标定白做
前置 2    : 动捕刚体系 R ≠ torso_link（§1.5）。先做 T_torso_R 对齐：与相机无关，
            可立即做；MoCap 模式把球转到 torso 系同样依赖它

目标      : T_torso_C = T_torso_R · T_R_C，单相机即可
硬件      : Unitree G1 —— D435 刚性固定在 torso_link（head_joint 为 fixed）
            故外参相对 torso_link，而非 pelvis
动捕刚体  : 贴 torso / 胸部。贴 pelvis 需用 3 个腰部关节做 FK 换算

路线      : A1 单球点对（动捕与相机测同一个球心） → AX=B，推荐
            A2 复合靶（ChArUco + 反光球）         → AX=ZB，需绕 ≥2 个非平行轴旋转

标定      : MVP（必做）：部署用的同一颗高反光球 + 同一套 IR 检测代码
                  联合估计 [外参, 径向偏移 r, 深度尺度 s]（物理参数化，§4.5 已证可辨识）
                  → T_R_C、在线补偿模型、RL 感知噪声域的实测依据
            交叉验证（条件触发）：复合靶 + RGB 角点重投影 → 独立外参
                  触发：MVP 验证不达标，或必须使用自由形偏置 b(z,θ)
            δt：外参固定后用动态数据单独标

实现      : Kabsch 初值（手写 / Rotation.align_vectors）→ least_squares + Huber
            残差按原生噪声空间构造；复合靶默认角点重投影
            ⚠️ cv2.estimateAffine3D：RANSAC 重载 = 12 DoF 仿射；Umeyama 重载在
               Python 下必估尺度 —— 都不是"带 RANSAC 的刚体配准"
采样      : MVP 200–400 球心，≥4 深度层，铺满可见区；诊断偏置形状时 400–800、≥5 层
            复合靶 30–60 位姿，板面绕 ≥2 个非平行轴旋转
            判据：点云协方差最小/最大奇异值比 ≥ 1/20
同步      : 机器人吊架静止；外参用静态采集绕开同步；δt 单独标（互相关或联合优化）
验证      : 留出集 + 对半一致性 + 与 CAD / 支架设计值对比（须先完成 §1.5）
排期      : T_torso_R 0.5–1 d · 选角 1 d · MVP 3–5 d · δt 1–2 d · 复合靶 1–2 周（可选）
```

## 0.5 前置阻断项：相机安装角与 FoV（必须先于标定解决）

### 0.5.1 问题

官方 URDF 中的相机安装姿态：

```xml
<joint name="d435_joint" type="fixed">
  <origin xyz="0.0576235 0.01753 0.41987" rpy="0 0.8307767 0"/>
  parent: torso_link  →  child: d435_link
```

`pitch = 0.8307767 rad ≈ 47.6°`，**光轴大幅下倾**。D435 深度视场约 **87° × 58°**（垂直半角 29°），RGB 约 69° × 42°：

```
光轴下倾            47.6°
垂直半视场          29.0°
─────────────────────────
视场上边缘         18.6°  （仍在水平线以下）
```

**官方安装姿态下，相机视场完全不覆盖水平线以上区域。**

**定量复核**：`unitreerobotics/unitree_ros`（master）的 `g1_29dof.urdf` 中 `d435_joint` 为 `rpy="0 0.8307767239493009 0"`、父节点 `torso_link`。腰部关节置零做 FK，相机在 pelvis 系下位于 `(0.054, 0.018, 0.474)` m；站立时 pelvis 离地 0.79 m，相机离地 ≈ 1.26 m。水平来球（8 m/s，接触点取手前伸 0.3 m）的可见窗：

| 球高 | 深度/IR（垂直 58°）可见的水平距离 | 首次可见距接触 | RGB（垂直 42.5°） |
|---|---|---|---|
| 0.6 m | < 1.97 m | ≈ 210 ms | < 1.34 m / ≈ 130 ms |
| 0.9 m | < 1.08 m | ≈ 100 ms | < 0.73 m / ≈ 55 ms |
| 1.2 m | < 0.19 m | ≈ 0 | ≈ 0 |
| > 1.26 m | 永不可见 | — | — |

对照 §0.5.3 的判据（首次可见 ≥ 接触前 0.4 s）与 HITTER 预测器实测（接触前 0.5 s 位置误差才降入容差），**官方姿态下没有任何区域满足**。是否改装已由几何决定，§0.5.3 的扫描只用于决定"改成多少度"。复核脚本：`calib_v3_checks.py` [1]。

该姿态是为行走避障 / 近处操作设计的；catch 任务来球在高处（入射 5–12 m/s、飞行 0.4–1.0 s、抛物线过顶），官方姿态下基本观测不到。

### 0.5.2 旁证（推断）

Goalkeeper 论文实测：相机模式成功率 14/30（MoCap 模式 21/30），失败**集中在低位区**（低区可观测窗 < 0.3 s），**上位区成功率反而高**。由此反推其 D435i 接近水平或上倾安装，与官方 CAD 姿态不一致。若沿用 URDF 的 `d435_joint`，感知条件会比 Goalkeeper 差得多，降级幅度不可比。

> 该反推未经作者确认；阻断结论已由 §0.5.1 独立成立，本节仅作旁证。

### 0.5.3 FoV 可见性扫描：选安装角（约 1 天，不依赖标定结果）

1. 输入：来球包线（入射 5–12 m/s、飞行 0.4–1.0 s、拦截点偏移中线 ±0.6 m），机器人名义站姿。
2. 对每条候选轨迹做视锥求交，计算**球在视场内的累计时长** `t_vis` 与**首次可见时刻距接触的剩余时间**。
3. 扫描安装角：官方下倾 47.6° 仅作对照，在 **0°（水平）至上倾 20°** 之间加密扫描，各输出 `t_vis` 热图（横轴入射区域，纵轴入射速度）。
4. 判据：`t_vis ≥ 0.3 s` 且首次可见 ≥ 接触前 0.4 s。阈值来源见附录 A #8。

**产出用途：**

- **定支架**：选覆盖最好的安装角，重新设计固定件；
- **定标定范围**：采样体积覆盖实际可见区，而非均匀铺满 FoV；
- **进论文**：作为 limitation 的定量依据，呼应 Goalkeeper 的 FoV 降级结论，说明主结果用 MoCap、相机结果作鲁棒性补充。

> **执行顺序硬约束**：支架重做会让已标外参全部作废。**FoV 扫描 → 定安装角 → 做支架 → 开始标定。**

### 0.5.4 通道差异：深度 / IR vs RGB（差 8°）

| 通道 | 垂直半角 | 视场上边缘（光轴下倾 47.6°） |
|---|---|---|
| 深度 / IR（58°） | 29° | **18.6°**，水平线下 |
| RGB（42.5°） | 21.25° | **26.4°**，水平线下 |

复合靶走 RGB 角点检测、或部署用颜色球时，可视角比深度/IR 窄约 8°。**FoV 扫描必须明确用哪个通道**，否则判定偏乐观。

### 0.5.5 安装角是多目标权衡

头部相机很可能同时承担行走 / 避障 / 导航，上倾会牺牲地面附近视野。FoV 扫描应加入**地面附近可见性**作为第二目标，输出 Pareto 前沿。若两目标严重冲突，§0.5.6 的双相机退路应提前评估。

### 0.5.6 若确认需要改装

- 改装后 URDF 的 `d435_joint` origin 只是占位值，标定结果直接覆盖。
- IR 滤镜方案（Goalkeeper §III-C）与安装角无关，可并行准备。
- 若机械上无法上倾，退路是**双相机**或**更宽视场的型号**，标定量翻倍，作为最后选择。

## 1. 场景与目标定义

### 1.1 系统构成

```
[动捕系统 W]  ──观测──▶  躯干上的动捕刚体 R          → T_W_R
      │                         │
      │                         └─ 常量 T_torso_R（§1.5 单独对齐）
      └──观测──▶  靶标 / 球                          → T_W_M（或球心 p_W）

[头部相机 C]  ──拍摄──▶  靶标 / 球                   → T_C_M（或球心 p_C）

本标定求  ：T_R_C
写回 URDF ：T_torso_C = T_torso_R · T_R_C
```

### 1.2 待求量的精确定义

| 问题 | 结论 |
|---|---|
| 相对哪个 link？ | **`torso_link`**（见 §1.4） |
| 相机系是哪个？ | RealSense 输出 optical frame（z 前 / x 右 / y 下）。标定得到 `T_torso_optical`，写回 URDF 前需乘 optical ↔ link 的固定旋转 |
| 动捕刚体贴谁？ | **torso / 胸部**。贴 pelvis 需要腰部关节 FK 换算 |
| 动捕给出的是哪个系？ | **刚体系 `R`**：原点与朝向由 FZMotion 中创建刚体时决定（可被“质心调整 / 刚体旋转”修改；默认是否为 marker 质心与世界轴，需实测）。**不是 `torso_link`**，二者差常量 `T_torso_R`（§1.5） |

### 1.3 术语约定

`T_A_B ∈ SE(3)`：把 **B 系**下的点变换到 **A 系**，即 `p_A = T_A_B · p_B`，`T_B_A = (T_A_B)^{-1}`。全文档、全代码统一此约定。

坐标系符号：`W` 动捕世界系；`R` 动捕在躯干上建立的刚体系（**不是** `torso_link`）；`torso` URDF 的 `torso_link` 系；`C` 相机系（默认 left-IR optical，见 §8 第 5 条）；`M` / `board` 相机观测的靶标系；`M_rb` 靶标上的动捕刚体系。

### 1.4 Unitree G1 的具体结论（已按官方 URDF 核实）

**来源**：`unitreerobotics/unitree_ros` → `robots/g1_description/g1_29dof.urdf`

```xml
<joint name="head_joint" type="fixed">          <!-- 头部没有自由度 -->
  <origin xyz="0.0039635 0 -0.054" rpy="0 0 0"/>
  parent: torso_link  →  child: head_link

<joint name="d435_joint" type="fixed">          <!-- parent 是 torso_link -->
  <origin xyz="0.0576235 0.01753 0.41987" rpy="0 0.8307767 0"/>
  parent: torso_link  →  child: d435_link
```

- `head_joint` 为 fixed → **"头部相机"实质是躯干相机，不存在云台问题**。
- **腰部自由度**：29 DOF 为 `pelvis → waist_yaw(z) → waist_roll(x) → waist_pitch(y) → torso_link`（yaw ±150°，roll/pitch ±30°）；23 DOF 仅 waist_yaw。
- `d435_link` / `mid360_link` 是空 link（无 visual/inertial），仅为占位坐标系，**不是真正的光心**。

| 项 | 结论 |
|---|---|
| 标定对象 | **`T_torso_d435`** |
| 为什么不是 pelvis | pelvis↔torso 之间有腰部关节，`T_pelvis_C` 随姿态变化 |
| 写回哪里 | 覆盖 URDF 中 `d435_joint` 的 `<origin xyz rpy>` |

**动捕刚体贴哪里：**

| 方案 | 需要腰部关节角？ | 说明 |
|---|---|---|
| 贴 **torso / 胸部** | ❌ | 动捕给 `T_W_R`，经常量 `T_torso_R`（§1.5）得 `T_W_torso`；**推荐** |
| 贴 **pelvis** | ✅ | 须同步记录 waist 三关节，`T_W_torso = T_W_pelvis · T_pelvis_torso(q)`；引入编码器误差 + URDF 误差 + 时间同步问题；刚体系 ↔ pelvis 对齐同样不能省 |

**其它注意事项：**

1. URDF 的 `d435_joint` 是 CAD 值，实机装配必有偏差——这正是要标定的量（若按 §0.5 改装，该值直接作废）。
2. D435 的 RGB 与 depth 之间有外参；复合靶（RGB）结果转到 depth/IR 系需要 `T_rgb_depth`（出厂值可由 librealsense 读取，需核查）。
3. 若用 pelvis 刚体，腰部 yaw 可达 ±150°，务必保证编码器与动捕时间同步。
4. **标定期间机器人不必站立**：只要求躯干与相机刚性连接且静止。吊在保护架上、低层阻尼模式供电（相机经机载计算机供电），可消除站立平衡控制的毫米级晃动；此时 `T_W_R` 为常数，可全程平均。

> 与主项目衔接：本节约定应与 `robot_params.yaml` 中的 canonical joint ordering 一起维护，避免 Pinocchio / MuJoCo / Isaac Lab 之间出现静默的轴序或坐标系不一致。

### 1.5 动捕刚体系 ↔ torso_link 对齐（P0）

**问题**：动捕输出的是 FZMotion 中建立的刚体系 `R`。本方案其余部分标出的是 `T_R_C`；写回 URDF、以及把相机观测转到策略所用的 torso 系，需要的是

```
T_torso_C = T_torso_R · T_R_C
```

`T_torso_R` 是与相机无关的未知常量。文献对应：Meta 的 camera-to-mocap 标定（arXiv:2604.22118）求的正是"平台动捕系 → 相机"，而非某个 CAD link；腿式机器人多相机外参标定（arXiv:1811.01254）引述的前序工作则把 marker 贴在机器人已知位置来消掉这一项。

**量级**：`T_torso_R` 旋转误差 1°，在 3 m 处造成 5.2 cm 球位置误差，相当于 Goalkeeper 全部感知噪声预算；平移误差 1:1 传入。

**为什么是 P0**：MoCap 模式把球转到 torso 系喂给策略（`p_torso = T_torso_R · (T_W_R)^{-1} · p_W`）同样需要它，因此它处在主项目 **MoCap 主结果**的关键路径上；相机外参只在鲁棒性补充结果的路径上。

**做法：网格特征点配准**

1. 确认 URDF 中 `torso_link` 的 visual `<origin>` 为零（否则先乘上），并确认 STL 长度单位；此时网格顶点坐标即 `torso` 系坐标。
2. 在躯干外壳上选 5–8 个可在网格上精确定位的特征（螺钉头、棱角、孔位），**分散、非共面**。头壳与 torso 为 fixed，可一并使用（经 `head_joint` origin 换算）以增大基线；头壳装配误差由第 6 步留一法检查。
3. 在特征处贴 marker；网格坐标沿表面法向补上"底座厚度 + marker 半径"，得到 marker 球心在 `torso` 系的坐标 `q_k`。
4. 机器人静止，从 FZMotion 导出 CSV，取**散点（Marker）列**作为单个 marker 的世界坐标 `p_W,k`（不用刚体位姿，也不用刚体资产点列），多帧平均；同时记录 `T_W_R`。特征点 marker 不并入躯干刚体资产。
5. Kabsch：`{q_k} → {p_W,k}` 得 `T_W_torso`，于是 `T_torso_R = (T_W_torso)^{-1} · T_W_R`。
6. 验证：留一法残差；换 2–3 个机器人位姿重复，`T_torso_R` 旋转差 < 0.5°、平移差 < 3 mm。

**精度粗估**（待实测）：单点定位 2–3 mm、基线约 0.2 m、6–8 点，旋转约 0.3–0.5°。不达标时，增大基线（加头壳点）比增加点数更有效。

**备选（仅作交叉检查）**：手腕贴刚体、运动手臂，由 `(T_W_R)^{-1} · T_W_hand,i = T_R_torso · T_torso_hand(q_i) · Z` 构成 `AX=YB` 问题。精度受 G1 FK 误差限制，不作终值。

**纪律**：`T_torso_R` 绑定于 FZMotion 中这一次的刚体定义。**刚体建立后不得删除重建、不得再用“质心调整 / 刚体旋转”，marker 不得移动**；任一项发生，§1.5 重做。导出的资产文件与 `T_torso_R` 一并版本化存档。

## 2. 技术路线：动捕同时观测靶标

每一帧 i：

```
T_W_M,i = T_W_R,i · T_R_C · T_C_M,i
```

三项都已知（两项动捕、一项相机），于是

```
X_i = (T_W_R,i)^{-1} · T_W_M,i · (T_C_M,i)^{-1}
```

经典手眼标定是 `AX=XB`，是因为靶标的世界位姿未知、被两帧相消；动捕直接测出这一项，问题退化为两组已知对应量之间的配准。但前提是"动捕测到的 `M`"与"相机测到的 `M`"是同一个系，由此分为两种形态。

### 2.1 A1 单球点对 与 A2 复合靶

- **A1 单球点对**：两边测的都是球心，严格的 **`AX=B`**，有闭式解、无旋转可观性禁区。
- **A2 复合靶**：动捕测靶标刚体系 `M_rb`，相机测 ChArUco 原点系 `board`，两者差一个未知常量 `T_board_Mrb`：

  ```
  T_C_board,i · T_board_Mrb = T_C_R · T_R_Mrb,i ,   T_R_Mrb,i = (T_W_R)^{-1} · T_W_Mrb,i     （AX=ZB）
  ```

  重新引入旋转可观性要求：靶标须绕 ≥2 个非平行轴旋转。

**共同代价**：靶标必须同时处在相机与动捕的公共视场内。

### 2.2 对比

| | A1（单球点对） | A2（复合靶） |
|---|---|---|
| 数学形式 | **AX = B**（点集刚体配准） | **AX = ZB**（多一个 `T_board_Mrb`） |
| 现成求解器 | Kabsch / Umeyama | `cv2.calibrateRobotWorldHandEye` |
| 可观性要求 | **点集空间展布充分**（§7.2） | **靶标绕 ≥2 个非平行轴旋转** + 空间展布 |
| 与部署感知管线一致 | ✅ 同一颗球、同一套 IR 检测 | ❌ RGB 通道 |
| 精化 | 闭式初值 + 原生噪声空间残差（§5、§6.2） | OpenCV 初值 + 角点重投影（§6.1） |
| 本项目定位 | **MVP，必做** | 交叉验证，条件触发 |

> ⚠️ 两者的可观性要求不同，采样策略不通用：easy_handeye 的 "minimize translation" 对 A1 有害；"maximize rotation" 对 A1 不必要，对 A2 是必要条件（§7.1）。

### 2.3 A2 的 OpenCV 映射：`cv2.calibrateRobotWorldHandEye`

OpenCV 的约束 `cTw · wTb = cTg · gTb` 与 A2 的约束逐项对应：world ↔ board、gripper ↔ 机器人刚体 `R`、base ↔ 靶标刚体 `M_rb`（注意 `world2cam` / `base2gripper` 的命名陷阱）：

| OpenCV 参数 | 对应 | 取值 |
|---|---|---|
| `R/t_world2cam`（输入） | `T_C_board,i` | ChArUco PnP 的直接输出（board → camera） |
| `R/t_base2gripper`（输入） | `T_R_Mrb,i` | `(T_W_R)^{-1} · T_W_Mrb,i` |
| `R/t_gripper2cam`（输出） | `T_C_R` | 取逆得 `T_R_C` |
| `R/t_base2world`（输出） | `T_board_Mrb` | 靶标的 board ↔ 动捕刚体偏置 |

已用合成数据验证：40 个位姿、无噪声下两个未知量恢复误差均 < 1e-11（`calib_v3_checks.py` [4]）。真机前仍按 §5.3 Step 3 用带噪合成数据跑一遍。

## 4. 标识物选型：MVP（单球）+ 条件触发的交叉验证（复合靶）

### 4.1 单球方案可行

「单个反光球只能拟合球心，3 DoF，给不出 6DoF」混淆了单帧可观性与整体可观性。标定求的是**一组点对的刚体配准**：几百个球心散布在视场体积内，6 DoF 完全可观（理论下限 3 个非共线点）。旋转精度由点云空间展布决定（§7.2）。

复合靶几何精度更高（RGB-PnP 亚像素 vs 深度点云拟合球心），但单球是唯一严格满足 `AX=B` 的形态（§2.1）。

### 4.2 场景特殊性：部署走 IR 通道

**部署感知管线是「IR 通道 + 高反光球斑点检测」，不是 RGB-PnP。** RGB-PnP 标出的外参几何上准，但**不包含**：

- IR 斑点质心 → 球心的系统偏置（形式取决于检测管线，§4.2.1）；
- D435 深度尺度偏差（与 `t_z` 强耦合，RGB 路径测不到）。

这两项恰恰是飞行球定位误差的主要来源。**结论：单球 MVP 必做，复合靶为条件触发的交叉验证（§4.3、§4.5）。**

#### 4.2.1 检测管线未确认 → 偏置形式未定（开工前必须确认）

| 管线 | 测到的是什么 | 偏置形式 | 原生残差空间 |
|---|---|---|---|
| **深度图取值**：IR 斑点定位后在 depth map 上取深度 | 球的**前表面** | 沿视线的径向偏移 `r ≈ 球半径`，叠加深度尺度 `s` | `(u, v, 视差)` |
| **双目 IR 三角化**：左右 IR 图各求斑点质心后三角化 | 近似**球心投影** | 无 `r` 项；斑点质心偏置（饱和、胶带接缝、透视） | `(u_L, v_L, u_R)` |

需实测的风险：回反射表面在主动立体下常出现**深度空洞**（可能迫使管线走三角化）；反光胶带接缝会让斑点质心偏离球心数毫米。

**动作**：拿到部署实际使用的检测代码（Goalkeeper 开源仓库或沿用的感知代码），确认走哪条，再定 §4.5 的参数化与 §6.2 的残差形式。

### 4.3 MVP + 条件触发的交叉验证

| 环节 | 靶标 | 检测通道 | 求解量 | 交付物 | 定位 |
|---|---|---|---|---|---|
| **MVP · 单球联合标定** | **部署时用的同一颗**高反光球（兼作动捕 marker） | **IR，同一套检测代码** | `T_R_C` + 物理偏置 `(r, s)` | 外参、在线补偿模型、RL 噪声域依据 | **必做** |
| **交叉验证 · 复合靶** | ChArUco 板 + 3–4 个非共面反光球 | RGB 角点重投影 | 独立的 `T_R_C` 及 `T_board_Mrb` | 与 MVP 外参对比 | **条件触发** |
| **δt** | 同一颗球，动态 | IR | 时间偏移 `δt` | 同步补偿 | 抛球实验前 |

**交叉验证触发条件**（任一）：① MVP 留出集或对半一致性不达标（§8）；② 残差呈现 `(r, s)` 解释不了的系统结构，必须改用自由形偏置 `b(z,θ)`——此时外参须由复合靶锚定（§4.5）；③ 需要论文级独立精度证据。

**复合靶要点：**

- 正面贴 ChArUco，侧面 / 立柱固定 3–4 个**非对称、非共面**反光球；球**不要与板面共面**，否则动捕端对绕板法向的旋转辨识度差；
- 两系统观测**同一刚体**，避免再做「板 ↔ 球」二次标定；
- 深度只作冗余校验 / 尺度参考；
- 材质用碳纤维 / 铝，板与球刚性固连，做好后不再拆装。

> **第二个未知量**：复合靶下 `T_board_Mrb` 未知，是 `AX=ZB` 而非 `AX=B`。成熟解法见 arXiv:2604.22118（Meta，2026-04），联合估计相机外参与 board-to-marker 变换，用**分阶段求解器**处理初值歧义，建议直接照搬其求解器结构与验证流程。OpenCV 初值映射见 §2.3。

**MVP 做法：**

1. 完成 §1.5（`T_torso_R`）与 §4.2.1（管线确认）；机器人按 §1.4 第 4 条吊架静止；
2. 手持球在**可见区**（§0.5.3 定角后的视锥）内逐点停稳，动捕给球心 `p_R,i`（刚体系下），IR 管线给 `p_C,i`；采样要求见 §7.3，采集实现与球尺寸见 §7.7；
3. Kabsch 初值 → 联合非线性精化 `θ = [rotvec, t, r, s]`（`r` 视管线固定为球半径或去掉），残差按 §6.2；
4. 按 §8 验证，通过后输出：
   - **外参** `T_R_C`，经 §1.5 得 `T_torso_C`，写回 URDF；
   - **在线补偿模型** `(r, s)`，接入白盒预测器的观测前处理；
   - **RL 感知噪声域的实测依据** —— 用留出集残差的实测分布替代 Goalkeeper 的 ±5 cm 经验值（其原文依据是"球半径的一半"）。

> 相关工具：`carlosmccosta/charuco_detector`（ROS ChArUco 检测）、`powei-lin/aprilgrid`（纯 Python）、`okalachev/arucogen`（ArUco 生成）。

### 4.4 复合靶的轻量替代：AprilCube

**AprilCube**：3D 打印立方体，6 个面贴 ArUco / AprilTag。

- 生成工具：[younghyopark/aprilcube](https://github.com/younghyopark/aprilcube)
- 优点：任意角度至少一面可见，多面联合估计位姿；可手持，无需支架。
- 实测案例：`sri299792458` 用 40 mm AprilCube 贴左手掌标定 G1 头部 RealSense；`tw1lightz` 把 AprilTag 固定在末端标定 G1（来源待补，见 §10.3）。
- **注意**：走 RGB 通道，同样受 §0.5.4 影响；**不能替代** MVP（IR 球心偏置仍须单独标）；与动捕联用时同属 A2（`AX=ZB`）。
- 也可用"G1 手臂举 Cube"做中间验证，但精度受 G1 FK 限制（HERO 实测 1.76 cm / 5.87°，来源待补），不能用于最终外参。

### 4.5 偏置参数化与可辨识性（决定复合靶是否必要）

"外参误差会被偏置模型吸收"取决于**偏置怎么参数化**。

**仿真设置**（`calib_v3_checks.py` [3]）：400 个球心，深度 1–4 m，铺满深度视场；噪声横向 2 mm、深度 `3 mm·z²`；由 Fisher 信息矩阵 `H = JᵀΣ⁻¹J` 求条件数与参数相关系数。

| 偏置参数化 | cond(H) | 与 `t_z` 的相关系数 | 结论 |
|---|---|---|---|
| 物理：沿视线的径向偏移 `r` | 2.0e2 | −0.43 | 可联合估计 |
| 物理：`r` + 深度尺度 `s` | 4.9e2 | `r`: −0.59；`s`: +0.49 | 可联合估计 |
| 自由形：`b = b₀ + b₁z`（沿光轴） | 3.6e16 | `b₀`: +0.99 | **奇异** |

**原因**：常数偏置与平移完全等价；任何含常数项、或对位置呈线性的自由偏置场，都会吸收一部分刚体变换。物理参数化的 `r`（方向随视线变化）与 `s`（改变点间距离，而刚体变换保距）不落在刚体变换子空间里。

**决策规则**：
- 物理参数化 → MVP 单独给出外参，复合靶为条件触发的交叉验证；
- 必须用自由形 `b(z,θ)` → 外参须由复合靶锚定，且 `b` 去掉常数项与线性项（或正交化到刚体子空间之外）。

**附带结论**：同一仿真下外参随机误差仅 ≤ 0.6 mm / ≈ 0.01°——随机误差不是瓶颈，系统误差才是（与 §7.2 一致）。

## 5. 实现选型：闭式初值 + 非线性精化

### 5.1 核心判断

- **优化器不手写，残差函数必须手写。** 加权方式（视差空间 / 各向异性）和附加参数（`δt`、球心偏置）是本场景特有的，现成库的默认损失都不包含。
- 闭式解只是**初值**，必须接非线性精化。
- A2 初值直接用 `calibrateRobotWorldHandEye`（§2.3）。

### 5.2 为什么闭式算术平均不够

「逐帧解 `X_i` → SE(3) 算术平均」有三处统计问题：

1. `X_i` 中的 `(T_C_M,i)^{-1}` 会把相机测量误差**按靶标距离放大**；
2. `np.mean(t)` 等权平均，让最差帧与最好帧同等发言；
3. 平移误差 ≈ 旋转误差 × 杠杆臂（靶标距离）→ 远处帧平移误差被二次放大。

chordal L2 旋转平均（`sum(Rs)` 的 SVD）在小散布下可作**初值**，问题只在于把它当终值。

### 5.3 流程

**Step 1 — 闭式初值**

- 点对形式（MVP）：Kabsch–Umeyama。去质心后 `H = Σ p̃_C,i p̃_R,iᵀ`，`H = UΣVᵀ`，`R = V·diag(1,1,det(VUᵀ))·Uᵀ`，`t = p̄_R − R p̄_C`。实现：numpy 手写、`scipy.spatial.transform.Rotation.align_vectors`，或 `Eigen::umeyama(src, dst, false)`；抗外点需在外面自套 RANSAC。
- 位姿形式（复合靶）：`cv2.calibrateRobotWorldHandEye`（§2.3）；逐帧 `X_i` + chordal 旋转平均只在 `T_board_Mrb` 已知时适用。

> ⚠️ **注意**（OpenCV 4.13 实测，`calib_v3_checks.py` [2]）：`cv2.estimateAffine3D` 两个重载都不是"带 RANSAC 的刚体配准"。
> - RANSAC 重载 `estimateAffine3D(src, dst[, ransacThreshold, confidence])` 拟合 **12 DoF 一般仿射**，会吸收尺度与剪切；
> - Umeyama 重载 `estimateAffine3D(src, dst, force_rotation=True)` **没有 RANSAC**，且 Python 绑定**总会估计尺度**（7 DoF 相似变换）。其返回的 `scale` 可作深度尺度 `s` 的初值。

**Step 2 — 加权 + 鲁棒非线性精化（终值）**

- 参数：`θ = [rotvec(3), t(3), (可选) δt, r_ball, s_depth]`；残差按原生噪声空间构造（§6）。
- 求解：`scipy.optimize.least_squares`，`loss='huber'`，`f_scale ≈ 2–3 ×` 残差中位数，`x_scale='jac'`。
- 复合靶（A2）精化参数为 `X = T_C_R`、`Z = T_board_Mrb` 两个 SE(3)，残差用角点重投影（§6.1）。
- 旋转用**旋转向量 / 四元数 + 流形**（Ceres `EigenQuaternionManifold`、Sophus、manif），**不用欧拉角**。

**Step 3 — 合成数据自测（做完才碰真机数据）**

随机生成点 → 乘已知 `R,t` → 加已知噪声 → 跑完整管线 → 检查能否恢复 `R,t`、估计不确定度是否与注入噪声自洽。真机数据混有误检、失步、坐标系错误，跳过此步会分不清是公式错还是数据脏。与项目现有的 fault-injection 自测纪律一致；`calib_v3_checks.py` 可作为起点。

### 5.4 库选型

| 库 | 用途 | 备注 |
|---|---|---|
| **numpy Kabsch / `Rotation.align_vectors` / Eigen `umeyama`** | 点集刚体配准闭式解 | 出初值；勿用 `cv2.estimateAffine3D` 代替 |
| **OpenCV 4.x** `calibrateRobotWorldHandEye` | AX=ZB | Shah2013 / Li2010；复合靶初值，映射见 §2.3 |
| **`scipy.optimize.least_squares`** | 非线性精化 | **第一版推荐** |
| **Ceres**（`Sophus::SE3`） / **GTSAM**（`Pose3`） / **g2o** | 高性能 / 联合优化 | 真机部署版再迁 |
| **liegroups / Sophus / manif** | SE(3)/SO(3) 流形运算与平均 | `pytransform3d` 只提供变换表示 |
| **Kalibr** | 时间同步标定方法参考 | 需要时延建模时参考 |

## 6. 损失函数与优化

### 6.1 复合靶（A2）：角点重投影残差

PnP 位姿协方差强各向异性（沿光轴的平移、绕板面内轴的旋转最不准），SE(3) 测地残差 + 固定权重等于让最差方向与最好方向等权，违背 §6.2 的原生噪声空间原则。Meta 的方法（arXiv:2604.22118）也是把靶标点沿整条变换链投影进图像。因此默认用角点重投影：

```
参数:  X = T_C_R,  Z = T_board_Mrb                                  （两个 SE(3)）
链路:  T_C_board,i(X, Z) = X · (T_W_R)^{-1} · T_W_Mrb,i · Z^{-1}
残差:  r_ij = ( u_ij − π(K, T_C_board,i(X, Z) · P_j) ) / σ_px         （每个角点 2 维）
损失:  E(X, Z) = Σ_i Σ_j  ρ_Huber( ‖r_ij‖² )
```

`P_j` 为 ChArUco 角点在板系下的坐标，`u_ij` 为第 i 帧检测到的角点像素，`π` 为含畸变的投影。初值来自 `calibrateRobotWorldHandEye`（§2.3）。

**SE(3) 测地残差仅作快速诊断**（逐帧残差排序定位离群帧），不出终值：

```
残差:  r_i = log( (T_W_R · X · T_C_M,i)^{-1} · T_W_M,i )  ∈ se(3)  (6 维)
```

### 6.2 点形式（MVP）：按原生噪声空间构造残差

深度噪声**在视差空间均匀、在深度空间平方增长**：

```
σ_z ≈ z² σ_d / (f · b)     （D435 基线 b ≈ 50 mm，σ_d ≈ 0.1–0.2 px）
```

2 m 处 σ_z 已有 1–2 cm，而横向像素误差只对应几毫米。各向同性 L2 会让远处点主导拟合，**旋转估计被拽偏**。

**首选（能拿到原始视差时）**：

```
r_i = [ (u_i − π_u(p̂_C,i)) / σ_uv ,
        (v_i − π_v(p̂_C,i)) / σ_uv ,
        (d_i − f·b/ẑ_i)     / σ_d  ]      # 第三维用视差，不用深度
```

**退路（只有 xyz 输出时）**：马氏距离 `r_i = L_i^{-1}(p̂_C,i − p_C,i)`，`Σ_i = diag(σ_xy², σ_xy², σ_z(z_i)²)` 旋转到视线系。

若 §4.2.1 确认走双目 IR 三角化，原生残差空间为 `(u_L, v_L, u_R)`，构造方式同上。无论哪种管线，偏置参数化都须满足 §4.5 的可辨识条件。

### 6.3 三件事（按优先级）

**① 时间同步 δt —— 一等公民**

| 物体速度 | δt = 5 ms | δt = 10 ms | δt = 20 ms |
|---|---|---|---|
| 手持移动 0.5 m/s | 2.5 mm | 5 mm | 10 mm |
| **来球 8 m/s** | **40 mm** | **80 mm** | **160 mm** |

8 m/s × 10 ms = 8 cm，比外参误差大一个数量级，直接吃光 Goalkeeper ±5 cm 的噪声预算。**策略：拆开处理。**

- **外参全部用静态帧**：移动靶标 → 停稳 0.5–2 s → 两边各取一段平均 → 记一个样本，彻底绕开同步。静态窗切分与配对见 §7.7。
- **δt 单独标**：外参固定后，用快速往复运动或抛球数据，动捕轨迹做 SLERP / 三次样条插值，扫描 δt 最小化残差；更省事的是对两边**速度模长**做互相关，峰值即 δt。
- 硬件手段优先级：硬件触发（FZMotion xSync 同步盒分频输出 → D435 硬件同步针脚，需确认电平）> PTP/PPS > 软同步（LuMoSDK 时间戳）+ 互相关。MVP 阶段先走软同步。

**② 各向异性权重 Ω**：动捕误差各向同性、毫米级；相机 z 向误差随距离平方增长。按传感器、按方向加权（`Ω_i = Σ_i^{-1}`）。

**③ 鲁棒核**：Huber / Cauchy（`f_scale ≈ 2–3 ×` 残差中位数），抗动捕遮挡跳变与误检；必要时叠 RANSAC 预筛。

### 6.4 更高精度路径

在 §6.1 基础上把动捕侧也下沉到原生测量：不用 FZMotion 输出的刚体位姿 `T_W_Mrb`，而用单个 marker（CSV 散点）的三维坐标联合进 BA，同时估计 marker 在靶标上的位置。精度最高、实现最重；复合靶仍不达标时再考虑。

## 7. 采样策略

### 7.1 常见误区

easy_handeye 的采样建议（maximize rotation / **minimize translation** / minimize target–camera distance）针对的是经典手眼标定 `AX=XB`——那里必须靠旋转激振才能解出平移。

- **A1（单球）**：无此要求，照搬会把点集挤成一团造成退化，"minimize translation" 是**有害建议**。
- **A2（复合靶）**："maximize rotation" 是**必要条件**（绕 ≥2 个非平行轴），"minimize translation" 仍不必要——既要旋转多样，也要空间展布。

### 7.2 A1 的可观性条件：空间展布

精度由观测点在相机视场体积内的空间展布决定：

```
旋转：δθ ≈ σ / (√N · L_min)      L_min 为点云在最弱主方向上的展布
平移：δt ≈ σ / √N
```

**N 下限（按目标精度反推）**：

```
目标 δθ = 0.1° = 1.75e-3 rad,  σ ≈ 10 mm（D435 @ 2 m）,  L_min = 0.5 m
⇒ √N ≥ 0.010 / (1.75e-3 × 0.5) ≈ 11.4   ⇒   N ≥ 130
```

N = 400 时 δt ≈ 0.5 mm——**随机误差不是瓶颈，系统误差才是**（§4.5 仿真独立印证：外参随机误差 ≤ 0.6 mm / ≈ 0.01°）。

### 7.3 采样量与分布

| 环节 | 样本数 | 每样本 | 分布要求 |
|---|---|---|---|
| **MVP · 单球** | **200–400 个球心**（下限 N ≥ 130）；诊断偏置随 `(z, θ)` 的形状时 400–800 | 静止 0.3–0.5 s 取平均 | **≥4 个深度层**（诊断偏置时 ≥5 层：1.0 / 1.5 / 2.0 / 3.0 / 4.0 m），每层扫满可见区四角与中心 |
| **交叉验证 · 复合靶** | **30–60 个位姿** | 静止 0.5–2 s 取平均 | ≥4 个深度层；板面**绕 ≥2 个非平行轴**旋转，正对与倾斜都要有（抑制 PnP 平面退化） |

### 7.4 三条硬性分布要求

1. **不能只用抛球轨迹采数据。** 轨迹近似直线 → 点近似共线 → 绕该直线的旋转不可观。必须手持球在整个视场体积内慢扫。
2. **必须跨深度层。** `s` 与 `t_z` 的解耦依赖深度展布，`r` 与 `t_z` 的解耦依赖视场角展布；§4.5 中 0.4–0.6 的相关系数是在 1–4 m、铺满视场的条件下得到的，展布不足时会升高。
3. **避免共面。** 共面时理论上可解，但条件数很差。

### 7.5 可观性自检（采完立刻做）

对相机系下观测点云去质心后求协方差，做 SVD 得三个主方向的展布及最小/最大奇异值比。

**判据：比值 < 1/20 说明某方向展布严重不足，回去补数据，不要硬解。** 把主方向展布代入 §7.2 的 `L_min`，可直接预估本次标定的 δθ。

### 7.6 多位姿 vs 每位姿多帧

纯随机噪声下，总有效帧数决定精度（∝ 1/√N）；但存在系统误差（检测偏置、刚体标定误差、热漂）时，只有增加**位姿/位置数**才能部分平均掉 → **「多位姿 + 每位姿多帧」**，不要少数位姿堆帧数。

### 7.7 采集实现

| 项 | 做法 |
|---|---|
| 机器人状态 | 吊架静止、低层阻尼模式供电（§1.4 第 4 条）；`T_W_R` 全程平均 |
| 录制链路 | 动捕侧以 FZMotion 录制 + **CSV 导出**为主数据源（散点 = 球心，刚体 = `T_W_R`）；VRPN **只传刚体**，单 marker 只能走 CSV（离线）或 LuMoSDK（在线）。`realsense-ros` 录 bag，可同时录 VRPN 刚体。两路按静止段顺序配对，CSV 的 `StartTime` + 相对帧时间即可满足粗同步。VRPN 与 CSV 的坐标系设置必须一致（建议 Z_Up） |
| 静态窗切分 | 两路各自按阈值切静止段（窗口内位置标准差 < 2 mm、持续 ≥ 0.3 s），段内取均值；**按顺序配对**，只需 NTP 级粗同步 |
| 配对校验 | 两路静止段数量应一致；数量不等或时长明显不一致 → 查漏检 / 遮挡，不强行配对 |
| 标定球尺寸 | 14 mm 标准 marker 在 3 m 处仅 2–3 px，相机检测不到；须用接近部署尺寸的球，并调整动捕的斑点尺寸 / 圆度过滤（HITTER 用反光胶带包球做动捕跟踪，可作先例） |
| 850 nm 双向互扰测试 | **方向一**：开 D435 发射器，看动捕是否掉点、是否出现假 marker（FZMotion 可设蒙版）。**方向二**：开动捕频闪，看 D435 IR 图是否出现假斑点。反光球在 IR 图中发亮依赖紧挨镜头的发射器（回反射），**不能靠关发射器规避** |
| 持球方式 | 手与手臂不遮挡动捕视线；持球杆用哑光材料；摘掉手表、戒指等反光物 |

## 8. 验证与精度评估

1. **留出验证集**：报告平移 RMS (mm) 与旋转 RMS (deg)，不只看拟合误差。目标（MVP）：3D RMSE < 2 cm（须显著小于 RL 噪声域 ±5 cm）；像素 RMSE < 2 px。
2. **对半一致性**：数据随机分两半各标一次，旋转夹角 < 0.5°、平移差 < 1 cm。比残差更能暴露过拟合与退化。
3. **收敛性**：残差应大致按 `1/√N` 收敛；不收敛 → 存在系统误差，按 §9 Step 7 排查。
4. **离群检查**：异常大残差 → 定位到动捕遮挡或误检的具体帧，回看原始数据。
5. **物理合理性**（须先完成 §1.5，否则 `T_torso_R` 会被误判为标定误差）：`t_torso_C` 与 CAD / 支架设计值相差应在几厘米、几度内。差太多通常是**坐标系定义错**（最常见：用了 color 帧而非 left-IR 帧；注意是否开了 depth-to-color 对齐）。
6. **下游端到端验证**：同一批抛球，纯相机管线预测落点 vs 动捕真值，画「落点预测误差 vs 距接触剩余时间」曲线，红线取抓取容差（手掌张开度 − 物体半径）。这是真正要交付的东西，也是论文 Fig. A 的相机版本。
7. **`T_torso_R` 验证**（§1.5）：留一法残差；多位姿重复，旋转 < 0.5°、平移 < 3 mm。
8. **MVP ↔ 复合靶一致性**（仅触发交叉验证时）：旋转夹角 < 0.5°、平移差 < 1 cm。沿光轴的平移差 → 偏置 / 尺度模型；整体旋转差 → 某一侧坐标系定义。

## 9. 实施流程

```
Step -1a ⚠️ 安装角（§0.5）：阻断已成立
         → FoV 可见性 × 地面可见性 Pareto 扫描，选角 → 做支架
         【支架重做会让已标外参全部作废】
Step -1b ⚠️ T_torso_R 对齐（§1.5）
         【与相机无关，立即可做；MoCap 模式同样依赖】
         动捕刚体从此冻结：不得重建、不得改 pivot / 朝向、marker 不得移动

Step 0  明确外参定义：T_torso_C = T_torso_R · T_R_C；相机系默认 left-IR optical
Step 1  确认检测管线：深度图取值 vs 双目 IR 三角化（§4.2.1）
         → 决定偏置参数化（§4.5）与残差形式（§6.2）
         核查 depth↔RGB 外参（内参已完成，§3）
Step 2  采集准备（§7.7）：吊架 + 阻尼模式；同一 bag 录制链路；850 nm 双向互扰测试
Step 3  合成数据自测（§5.3 Step 3）：能否恢复注入的 [R, t, r, s]
Step 4  【MVP】部署球，200–400 个静止位置，≥4 深度层，铺满可见区
         → §7.5 可观性自检（奇异值比 ≥ 1/20）
         → Kabsch 初值 → least_squares 联合估计 [rotvec, t, r, s]，Huber
         → 验证：留出集 + 对半一致性 + 与支架设计值对比（§8）
Step 5  单独标 δt（动态数据 + 互相关 / 联合优化）
Step 6  （条件触发，§4.3）复合靶交叉验证
         calibrateRobotWorldHandEye 初值（§2.3）→ 角点重投影精化（§6.1）
         → 与 MVP 外参对比（§8 第 8 条）
Step 7  残差过大时的排查顺序：
         时间同步 → 内参 → 刚体是否松动 / 被重建 → 靶标检测 → 坐标系定义 → T_torso_R
Step 8  写回 URDF / tf（乘 optical ↔ link 固定旋转）；下游端到端验证（§8 第 6 条）
```
