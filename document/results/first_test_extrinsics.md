# first_test 两种方法的外参候选

**状态：`unverified`，不可部署。** 以下是板法和单球法的两个同方向矩阵，来源为本地 `outputs/calibration/first_test_inferred_v3/report.json`；完整精度见 [JSON 摘要](first_test_extrinsics.json)。

## 坐标约定

- 两个矩阵都是 `T_W_C`，将 D435i **color optical** 相机坐标 C 转到动捕导出 World 坐标 W。
- `p_W = R_W_C · p_C + t_W_C`，点与平移单位为 **m**。
- 不等于机器人 `torso_link` 外参，也不等于 `T_R_C`。
- 单球矩阵不含尺度：先将原始深度转换为米并得到球心，才应用此刚性矩阵。

## 1. 板角 RGB-PnP

```text
T_W_C_board =
[[-0.99813210, -0.05697033,  0.02206090, -0.06853007],
 [ 0.01103776, -0.52333053, -0.85205829,  1.22565353],
 [ 0.06008718, -0.85022323,  0.52298182,  0.85392651],
 [ 0.00000000,  0.00000000,  0.00000000,  1.00000000]]
```

重投影 RMSE 约 **0.353 px**。使用反光 marker 的二维轮廓中心和动捕实测三维球心，不需要 ARCode 码尺寸。图像中心对应球心的模型偏差仍需核验。

## 2. 单球 RGB-D 相似变换推导

```text
T_W_C_ball =
[[-0.99267677, -0.09644347,  0.07274265, -0.08733918],
 [-0.01556064, -0.49506704, -0.86871543,  1.24053929],
 [ 0.11979442, -0.86348554,  0.48994082,  0.85751233],
 [ 0.00000000,  0.00000000,  0.00000000,  1.00000000]]
```

三个位置训练拟合 RMSE 约 **2.83 mm**，并非独立验证精度。推导深度单位约 **0.001007078 m/raw**，轮廓等效面积推导半径约 **6.87 mm**；这些不是设备配置或尺测事实。

## 交叉检查

两个候选相差约 **4.206° / 24.25 mm**。尚不能认定同一安装状态下结果一致，不应直接融合、部署或写成实机验收通过。
