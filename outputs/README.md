# 结果目录

- `calibration/<session_id>/<version>/`：变换矩阵、frame、补偿参数、配置/资产引用、版本与验收状态。
- `reports/<session_id>/<version>/`：输入质量、展布、样本配对、torso 留一/重复、留出位置与像素误差、分半一致性、分深度/视场报告。

完整契约见 [工作区接口](../document/design/工作区约定与接口.md)。当前目录只有占位文件，**没有已标定结果**。

`T_torso_C = T_torso_R · T_R_C`；如需相机 link 外参，则 `T_torso_L = T_torso_C · T_C_L`。深度尺度与径向补偿单独保存，不放进 SE(3) 矩阵。未知变换不能输出占位单位矩阵。

只有独立静态验收通过的标定包可发布。失败/未验证包保留状态与报告，不修改机器人 URDF；后续导出器应默认禁止自动覆盖正式部署配置。原始数据、资产或配置变化时保留旧版本并按核心流程重新核查。

结果目录在 `.gitignore` 中默认忽略，需要独立备份，不以版本控制代替数据归档。
